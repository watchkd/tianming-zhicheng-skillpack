# 01 · 命局取用规则

> 本文件是「择城知运」第二步（分析原局、提出候选喜用）的执行依据。

## 〇、分级体系与三条术语警告（V1.4 新增，先看再往下）

### 0.1 分级体系：从单维改为双维

V1.3 及以前只按"依据类型"分级，把"《滴天髓》十三·体用"这种**技能包里的章节号**当成了"原文可查"。这是不诚实的——章节号来自蒸馏包的整理，本技能**没有回图核过原书**。

V1.4 起改为**双维**：类型 × 载体，两个都要标。

**维度一：依据类型**（这条结论是怎么来的）

| 级 | 含义 |
| --- | --- |
| **甲** | 原文可查，能给出书名与篇章 |
| **乙** | 义理归纳，可追溯到某书某派主张，但非逐字原文 |
| **丙** | 现代推演或经验归纳，古籍无对应条文 |
| **丁** | 民间说法，**禁用** |
| **CONV** | 本技能自定的口径与算法。**不是知识，是规矩**——错了叫"规矩定错"，不叫"推演不准" |

**维度二：载体**（这条结论我实际看到的是什么）

| 载体 | 含义 | 强度 |
| --- | --- | --- |
| 原书 | 已核原书或影像（回图目验） | 最强 |
| 整理本 | 可靠整理本、多本互证 | 强 |
| 电子文本 | 电子文本 / 网站转录，未回图 | 中 |
| 技能包 | 二手蒸馏技能包，未回溯原书 | 中偏弱 |
| 本技能 | 自建（同 CONV） | — |

### 本文件的诚实声明（必读）

**本文件所有标"甲"的条目，载体绝大多数是「技能包」，少量是「电子文本」，无一条是「原书」。**

原因：本技能的四本古籍来自 `gitcode.com/jyjy2025` 的蒸馏技能包，章节号是包内整理的编号，未经回图核对。所以严格写应该是：

```
甲（技能包）· 《滴天髓》十三·体用
甲（电子文本）· 《三命通会》卷四得地条
乙（本技能）· 五行需求向量
CONV（本技能）· 主从裁决顺序
```

**引用纪律**：
- 对外只能说"依《滴天髓》体用章（据蒸馏技能包整理）"，**不能说"原书如此"**
- 若某条结论会直接改变推荐结果（如主需判反了），报告里须注明"此条依据为技能包整理层，未回原书"
- 想升到"原书"级，必须回影像或纸质本逐字核 —— 本技能**当前没有做，也不假装做了**

### 0.2 三条术语警告

这三条不是知识，是**防混用的护栏**。不看这三条，后面 §2 的三栏对照必然做错。

#### 0.2.1 "用神"是个歧义词，至少有四义

| 谁在用 | 指什么 | 判断标准 |
| --- | --- | --- |
| 格局法（《子平真诠》） | **月令所成之格**的那一位 | 月令透干、格之成败 |
| 扶抑法（《滴天髓》） | **补日主强弱所需**的那一位 | 日主旺衰、该扶该抑 |
| 调候法（《穷通宝鉴》） | **调寒暖燥湿**的那一位 | 生月气候、有无根 |
| 后世命书（混用） | 以上三者随便一个 | 无标准 |

**所以本技能一律不写"你的用神是火"，而写"格局用神是 X、调候用神是 Y、扶抑用神是 Z"**，三个分开说。§2 的三栏对照卡就是这个意思。

> 出处：本条为 **CONV（本技能）**，但四义本身可追溯——《子平真诠·论用神》专求月令；《滴天髓》十三·体用讲扶抑；《穷通宝鉴》讲调候。三者确实各说各话。

#### 0.2.2 "月令为提纲"不是所有体系都认

| 体系 | 月令的地位 |
| --- | --- |
| 李虚中—五行精纪线（年/纳音为纲） | **无地位** |
| 渊海子平线 | **时间分限** |
| 三命通会线 | **提纲**（月令定用神的前提） |

本技能默认走**三命通会线的"月令提纲"**（因为择城用的调候表也在这条线上）。但要知道：**这是选择，不是定论**。若命局明显是年柱主导（如年柱干支一气、月令被合去），应改走年纲视角并说明。

> 出处：**乙（电子文本）**，据《三命通会》论月令、《渊海子平》相关篇目整理层；体系分线参照徐子平 Bot 项目的 C-02 概念比较条（该条自标 B2）。

#### 0.2.3 沈孝瞻原文 ≠ 徐乐吾评注

《子平真诠》是清·沈孝瞻（康熙年间）原著，民国徐乐吾作评注。**两者相隔两百多年，评注是后出的解释材料。**

| 常见混淆 | 实情 |
| --- | --- |
| "《子平真诠》说调候为急" | 调候为急是**徐乐吾评注**反复强调的，沈氏原文未必如此 |
| "《子平真诠》说透干为真格" | 需回原文核；本技能所见为整理层转述，**标"待核"** |

**引用纪律**：
- 能确定是沈氏原文的，写"《子平真诠》原文"
- 只能确定是评注的，写"徐乐吾评注"
- 分不清的，**写"《子平真诠》系（原文/评注未分）"**——不许硬派给沈孝瞻

> 本技能目前的状态：**§4 引的《子平真诠》条文，多为整理层转述，未逐条区分原文与评注。凡涉及处已标"待核"。** 这一条如实登记，不掩饰。

## 一、第一件事：取用不是"缺什么补什么"

这是择城类问题最容易走偏的地方。用户往往一上来就问"我五行缺火，是不是该去南方"，这个推论链有三处断点：

| 错误推论 | 错在哪 | 正确做法 |
| --- | --- | --- |
| 八字缺火 → 喜火 | 缺 ≠ 需。缺的可能是忌神，也可能是"不需要但无害" | 先判旺衰格局，再看该行是病是药 |
| 喜火 → 去南方 | 方位五行只是"环境加成"，不是决定项 | 方位、地域、现实条件三者分列 |
| 去南方 → 必发 | 命理信号是概率倾向，不是因果 | 只给"值得优先考察"，不给"必然成功" |

**铁律：五行缺失、五行数量、五行多寡，都不能直接等于喜用。**

> 《穷通宝鉴》体系明确反对机械补缺（"缺而不需者不补"）；《滴天髓》则以"得不得用"为断——**用神不在"有没有"，而在"得不得用"**（十三·体用）。

## 二、三用神并行，不是三选一

十部子平经典对"用神"有六种定义，强行只取一个会系统性漏判。正确做法是**同一八字并行开三个视角取用，再按固定主从裁决**。

| 视角 | 名称 | 回答什么 | 供给书 | 产出 |
| --- | --- | --- | --- | --- |
| ① | **格局用神** | 这八字是什么格、档次如何 | 子平真诠（主轴）+ 千里八格 + 约言取格链 | 格名 + 成破 + 层次 |
| ② | **调候用神** | 寒暖燥湿缺什么气、格局喜忌是否要因调候转弯 | 穷通宝鉴（十干十二月）+ 滴天髓寒暖燥湿 | 补偏字 + 是否"调候为急" |
| ③ | **扶抑用神** | 日主强弱、该扶该抑、通关为何 | 滴天髓 + 千里命稿 + 神峰病药 | 身强弱 + 喜忌 + 药 |

### 2.1 主从裁决顺序（冲突时谁压谁）

```
优先级（从高到低）：
1. 特殊格（化气 / 从格 / 专旺）   —— 一旦成立，直接接管，不套正格
2. 调候为急（冬夏生人 + 身弱用印 / 寒木向阳） —— 与格局正面冲突时，调候优先
3. 格局用神（正格范围内的成破、层次） —— 常规断命的主裁决
4. 扶抑校验（身强弱自洽检查） —— 只校准，不推翻；不自洽则标"流派分歧"
```

### 2.2 三条裁决原则

1. **特殊格优先**：正格法对专旺/从格/化格会系统性误判，所以特殊格判定必须在正格之前。
2. **调候不臣服格局**：徐乐吾评注反复以"调候为急"纠正沈孝瞻的表层归类，这是子平系内部公认的"调候压格局"先例。
3. **扶抑只校验不判案**：格局法出主结论，扶抑结论并列呈现，标注"此二法在此盘上同判/异判"。

### 2.3 输出必须是三栏对照卡

```
┌────────────────────────────────────────────┐
│ 格局用神：X（X格，成/破/混杂，层次：上/中/下） │
│ 调候用神：Y（是否"调候为急"，与格局同向/相左）  │
│ 扶抑用神：Z（身强/弱，该扶/抑，通关字）        │
│ ───────────────────────────────────────── │
│ 主裁决：……（以谁为准、分歧在哪、双说并陈）      │
└────────────────────────────────────────────┘
```

> 铁律：三视角**必须都跑**，即使结论一致也要写明三者各自是什么。缺一视角即算漏断。

### 2.4 同一个五行，在三路里可以吉凶相反（V2.1 新增）

三栏对照不是为了"投票"，是因为三路问的本来就不是同一件事：

| 路 | 它问的问题 | 水在这个问题里的角色 |
| --- | --- | --- |
| 格局 | 这个格靠什么成立？ | 正官格用印 → **成格之字** |
| 调候 | 这个气候缺什么、忌什么？ | 酉月甲木"忌癸制丙" → **坏字** |
| 扶抑 | 日主撑不撑得住？ | 身弱喜印 → **帮身之字** |

所以同一个"水"，可以同时是成格之字、坏调候之字、帮身之字。**这不是矛盾，是三个不同的问题。**

**处理规则三条**

1. **不许合并成一个"水的吉凶"。** 要写"水在格局层为喜、调候层为忌、扶抑层为喜"，三句并列。
2. **向量里只能落一个位置**，所以必须写明"这个位置是按哪一路定的"。例：水定为**次需**，是按扶抑与格局定的；调候的反对意见记入**存疑**栏，不许省略。
3. **"存疑"栏不是"不知道"，是"两路打架、本次按某一路取、另一路留案"。** 写报告时要让用户看见这条分歧，不能只给结论。

> **对择城的直接影响**：若某五行在扶抑为喜、调候为忌，那么"往该方位去"只能算**弱合**，不能算强合。理由是——地域补的是**长期居住环境**，调候之忌会年年生效，不像大运只走十年。这一条不写清，就会把"勉强可用"写成"首选"。

## 三、第 1 步 · 辨体（先判特殊格，再判强弱）

### 3.1 先判特殊格 —— 成立则跳过正格

> 《滴天髓》十·形象："独象喜行化地，而化神要昌。"

| 格 | 成立条件 | 喜 |
| --- | --- | --- |
| 曲直格 | 木日，寅卯辰或亥卯未全、**不杂金** | 行化地（火） |
| 炎上格 | 火日，巳午未或寅午戌全、**不杂水** | 顺其炎上 |
| 稼穑格 | 土日，辰戌丑未四库全、**不杂木** | 顺其厚载 |
| 从革格 | 金日，申酉戌或巳酉丑全、**不杂火** | 顺其刚锐 |
| 润下格 | 水日，亥子丑或申子辰全、**不杂土** | 顺其润下 |
| 两气成象 | 两气各半相生（土金/金水/水木/木火/火土） | 象不可破 |
| 两气相克 | 务须**均敌** | 偏重则破 |

**从格要件**（三说合流）：

```
弃命无根（日主无根无气）
  + 独神势成（满官从官、满财从财）
  + 顺月令盛衰（辰月木竭可从，未月木尚有气不可从）
```

> 出处：滴天髓·形象 / 从象；命理约言从局法；穷通宝鉴三月甲木条。三说合并见 §10 分歧 5。

### 3.2 再判强弱 —— 四维

> 《滴天髓》十七·衰旺："能知衰旺之真机，其于三命之奥，思过半矣。"

| 维度 | 判据 | 权重 | 出处 |
| --- | --- | --- | --- |
| **得令** | 月支五行对日干是生扶还是克泄耗 | **最高** | 滴天髓·月令 |
| **得地** | 日干在四支藏干中有无同五行（有根） | 高 | 滴天髓·地支 |
| **得生** | 天干有无印星透出且有力 | 中 | 十神·印 |
| **得助** | 天干有无比劫透出且有力 | 中 | 十神·比劫 |

**关键分句**：
- 月支生扶日干 → 得时当权，气势旺
- 月支克泄耗 → 失时，气势衰
- **日干有根，虽失令不作弱论**（这条最常被漏）
- 印星透干有力 → 衰而可用
- 比劫透干 → 弱而能任

**时柱加权**：生时逢禄刃（日主临官/帝旺）→ 晚岁得力，身偏旺；生时逢食伤 → 秀气归时，泄身有力。

输出：**身强 / 偏强 / 中和 / 偏弱 / 身弱** 五档，并注明"强在何处、弱在何处"。

> **易错点**：地支藏干的中气余气算不算通根，各家不一。本技能取"本气为根、中气为次根、余气仅助势"，并在报告里注明这一取舍。

### 3.3 旺极弱极不可扶抑

> 《滴天髓》十三·体用："旺极者抑之，抑之反激而有害，则宜从其强而扶之；弱极者扶之，扶之徒劳而无功，则宜从其弱而抑之。"

| 触发 | 结论 |
| --- | --- |
| 身旺、满局比劫 | 宜泄（食伤顺其性），**不宜抑**（克激而有害） |
| 身旺、财官无气 | 伤之（去比劫有余）比泄之有利 |
| 身弱、财星重叠 | 帮之（比劫）去财补身 |
| 身弱、官杀满盘 | 助之（印）化其强暴，**不宜帮**（比劫受克） |
| 旺极（专旺/从强） | 不可抑，宜从其强 |
| 弱极（从格） | 不可扶，宜从其弱 |

## 四、第 2 步 · 定局（格局取用）

### 4.1 取格

> 《子平真诠·论用神》："八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。"

> 《滴天髓》十二·八格："月支之神透于天干，为真格。"

| 月令 | 常规取格 | 备注 |
| --- | --- | --- |
| 子午卯酉（四正） | 本气透出取本气格；不透看月令所藏 | 四正之月，气专 |
| 寅申巳亥（四生） | 本气透出取本气格；多取长生之气 | 气杂，须辨谁当令 |
| 辰戌丑未（四墓） | 本气透出取本气格；不透论"杂气" | 最易判错 |

**顺用逆用**：财官印食（善神）顺用——生护；杀伤刃（凶神）逆用——制化。

**比劫禄刃不取格**（真诠/千里/约言三家一致），只为日主之助；建禄/月劫另作专论。

### 4.2 体用取用九条（《滴天髓》十三·体用）

> 原文："道有体用，不可以一端论也，要在扶之抑之得其宜。"

**但先做一件事：判这个盘有没有病、药是什么**（V2.1.3 前置，理由见 §6.2 与 §九 误判 12）

体用九条是**按日主状态查表**，它不问你"这个盘有没有病"。而一旦盘中有明确的破格之神，"弱什么补什么"式的查表就会把**病位**当成**药**。

**前置两问（查九条之前必须回答）**：

| 问 | 怎么答 | 若答案是"有" |
| --- | --- | --- |
| ① 有没有一个明确的"破"？ | 回 §4.3 第③步。破格之神是谁、破了什么 | 记为**病** |
| ② 谁是"克这个破"的那一行？ | 找克病神者 | 记为**药**，**药优先入主需** |

**判据一句话**：**被克的一方是病位，克它的那一方是药。用神取药，不取病位。**

> **实测教训（V2.1.3，庚金亥月·财破印）**：日主庚金偏弱，食伤（水）旺、财（木）旺。按九条查表，"弱、食伤多→印绶"给出土，"弱、财星旺→比劫"给出金。上一版取了土。
> **错在**：土正是被木克的那一方（财破印），补土等于往正在被克的位置再堆土，木照样克。
> 而金克木——金一进，木被制、土松绑、身有帮，**一药治三病**。
> 若走了前置两问，第一问就会答"有破，破在财破印"，第二问答"克木者是金" → 直接取金，不会走错。

| 日主状态 | 用神 | 理由 |
| --- | --- | --- |
| 旺、印绶多 | **财** | 制印 |
| 旺、官杀轻 | **财** | 生官 |
| 旺、比劫多而抗财 | **食伤** | 泄劫生财 |
| 弱、官杀旺 | **印绶** | 化杀生身 |
| 弱、食伤多 | **印绶** | 制食扶身 |
| 弱、财星旺 | **比劫** | 帮身任财 |
| 日主与官杀两停 | **食伤** | — |
| 日主与财星均敌 | **印比** | — |
| 化之真者 | 以化神为体，取生克化神者 | 化格专用 |

> **表内两条同时命中时**（如"弱、食伤多"与"弱、财星旺"并存）：**不许随意取一条，回 §6.2 病药法裁决。** 两条并列而盘中有明确破格之神时，药优先。

### 4.3 格局判定五步链条（V1.4 升级，替代原"成/破"二分）

V1.3 只有"成 / 破"两档，等于只回答"这格立不立得住"。但要判**层次**、要判**择城时该不该押这个格**，两档不够。

五步（顺序不可颠倒）：

| 步 | 做什么 | 关键提问 | 择城场景为什么要它 |
| --- | --- | --- | --- |
| **① 定格** | 月令本气/余气/透干/会支，定出格名 | 这个格的"神"是谁？是格局神还是扶抑神？ | 定不出格，后面全是空谈；且要先分清"神"指哪个（见 §0.2.1） |
| **② 看成** | 该格需要的生扶、护卫、顺逆配合是否具备 | 格神有没有根？有没有被夺？ | 决定"这个格值不值得押" |
| **③ 找破与救** | 克、冲、合去、混杂、位置先后；再看制化、合清、会解是否真有效 | 破在哪？救得回来吗？ | **破格之神往往是"忌神"，直接进需求向量的"忌"栏** |
| **④ 衡清浊与力量** | 关键字有根否、配合流通否、忌神清除了否 | 是"清"还是"浊"？有力还是虚浮？ | 清而有力 → 主需可信；浊而无力 → 主需存疑，进"存疑"栏 |
| **⑤ 看岁运如何作用** | 每步大运回到原局结构，看它扶成、损坏、引出、合去、转变了什么 | 这步运是把格扶起来还是打散？ | **择城的时间尺度就是大运尺度，这一步不能省**（见 §7.5） |

**四条纪律**：

1. **不许凭一个十神名目直接定贵贱。** "正官格"三个字不说明任何事，要看②③④。
2. **不许虚构精确的社会等级。** 写"上/中/下"三档即可，不写"厅局级""千万富翁"——那不是命理能给的东西。
3. **不许把"成格"当结论。** 成格只说结构成立，不说这人一定顺；还要看运。
4. **不许把某五行贴成永远的吉运。** "走水运就好"这种话，在①—④没走完之前不许说。

> 五步顺序出自《子平真诠》格局法（定格—成败救应—清浊力量—行运）的组织方式，经徐子平 Bot 项目整理为可执行链条。
> **载体说明**：本条的"顺序"是**乙（技能包+项目整理）**；其中"定格以月令为入口""善神顺用凶神逆用"可追溯《子平真诠》，但**原文与徐乐吾评注未逐条区分**（见 §0.2.3），标"待核"。

### 4.4 原"成/破"四条判据（保留，作为第②③步的细则）

| 触发 | 结论 |
| --- | --- |
| 月支之神透于天干 | 为真格（第①步用） |
| 格正用真、行运不悖 | 名利自如（第②步通过 + 第⑤步顺） |
| 格破用损、行运去病得所 | 不贵亦富（第③步有救 + 第⑤步补） |

**用神唯一性**：主用神只定一个（格局定名后的真用神），其余为相神/喜神。避免"满盘都是用神"的虚断。

## 五、第 3 步 · 调候修正

> 详细查表见 `01a-调候速查表.md`。此处只给流程与优先级。

### 5.1 四步

1. **候气候**：冬生（亥子丑）→ 寒，喜火；夏生（巳午未）→ 暖，喜水。燥（戌未+火多）→ 喜金水；湿（辰丑+水多）→ 喜火土。
2. **查月**：按出生月 + 日干查 `01a` 的十干×十二月表，读出**用神序列（先 X 后 Y）+ 喜 + 忌**。
3. **定有根无根**：寒命要火有根、暖命要水有根（"癸无源等于无"）。无根则偏枯，不轻许富贵。
4. **与格局/扶抑合流**：见 §2 主从裁决。

### 5.2 优先级（本步最关键的一句）

| 生月 | 调候权重 | 与格局冲突时 |
| --- | --- | --- |
| 冬夏（亥子丑 / 巳午未） | **高**，"调候为急" | **调候优先，标注冲突** |
| 春秋（寅卯辰 / 申酉戌） | 低 | 格局为主，调候只作修正与喜忌走向 |

**例外：特殊格成立时，调候可能整条作废**（V2.1 补例）

调候默认"日主宜中和"，所以它给的是"补偏"之字。但专旺格/从格要的是**顺其气势**，两者方向可能正好相反。

实例：甲寅·丁卯·甲辰·甲子，曲直格（专旺木）。
- 查〔卯甲〕：**庚丙丁（先庚后丁）**，喜庚金劈甲 → 调候要金
- 但曲直格木极旺、全局无金，金一进来就是**破格**
- → **调候的庚金整条作废**，只取丙丁（泄秀），且火升为主需

**判法一句话**：先问"调候要的那个字，是不是这个格局的忌神"。是 → 调候作废，在报告里写明"调候不适用，因与格局忌神重合"，**不许悄悄丢掉不提**。

### 5.3 四条禁止

1. **把调候喜神当用神**。喜火只是暖局，火无根不可执为用神（"取火为用者十无一二"）。
2. **口诀序列取反**。正月甲木是"先丙后癸"，不是"先癸后丙"。
3. **月内分界不辨**。五月乙木夏至前后用法相反，六月壬水大暑前后不同。
4. **专旺格照抄调候**。调候要的字若正是格局忌神，整条作废，须写明，不许默默采用也不许默默丢弃。

## 七、五行需求向量（本技能的核心产出）

前三步合参后，输出**不是单一"喜某行"**，而是一个向量：

```
主需：__行   （最强指向，通常只有一行）
次需：__行   （辅助，0-2 行）
忌神：__行   （明确有害）
仇神：__行   （助忌神者）
存疑：__行   （两派结论冲突，或证据不足）
```

### 为什么必须是向量

城市方位只能落在一个方位五行上（东木/南火/西金/北水/四维土）。当主需与次需指向不同方位时，必须靠优先级取舍，而不是含糊地"都行"。

### 填法

| 项 | 从哪来 |
| --- | --- |
| 主需 | 三视角合流后的主用神五行 |
| 次需 | 相神/喜神五行 |
| 忌 | 破格损用之神 |
| 仇 | 生忌神者 |
| 存疑 | 三视角异判且无法裁决的那个 |

**调候为急时**，调候所需五行应直接进入"主需"或与主用神并列，并在报告里注明"此为主需，因调候为急"。

### 7.5 用神会不会随大运变？（择城场景的关键限定，V1.4 新增）

这一节是本文件 V1.4 最重要的补充。原因很简单：**择城要回答的是"未来 5–10 年"，而这期间通常跨 1–2 步大运。如果"喜什么"在换运时变了，那么"去哪个城市"的答案也会跟着变。**

#### 7.5.1 三说并存

| 说 | 主张 | 出处层次 |
| --- | --- | --- |
| **不变说**（主流） | 用神由原局定，大运只是"用神得不得力"，不改用神本身 | 扶抑法、格局法通行的做法 |
| **随运成毁说** | 用神随大运而变，运来则成、运去则毁 | 《三命通会》系有此说（**乙·电子文本**） |
| **改格说** | 大运可能改变格局本身（如从格遇破、正格遇合化） | 从格/化格专论 |

**本技能不选边，而是分层处理**：

#### 7.5.2 分层处理法（择城口径，CONV）

把"喜用"拆成**两层**，一层不随运变，一层随运变：

| 层 | 内容 | 随运变吗 | 怎么用 |
| --- | --- | --- | --- |
| **底层（不变）** | 日主强弱格局、调候所需（寒暖燥湿）、破格忌神 | **不变** | 决定"这个人本质上缺什么"，是择城的**长期底色** |
| **表层（随运）** | 大运带来的五行是否已补足某项需求、是否引入新的病 | **变** | 决定"这十年里缺什么"，是择城的**阶段修正** |

**关键判断**：某一行若大运已强力补足，则该行在**该运内**从"主需"降为"已满足"，不必再靠地域去补。

举例（构造，非真实命例）：
```
底层：日主丙火偏弱，喜木生（长期底色 → 木）
当前大运：甲寅（强木运）
→ 木在运中已得强补 → 这十年"缺木"的问题已解决
→ 择城时不必再死守东方（木），可以转看次需（如土/金）
下一运：庚申（金运，克木）
→ 木被伤，重新成为急需 → 择城回到东方
```

**这个例子说明一件事：同一命局，换运前后可能给出相反的择城结论。这不是前后矛盾，是时间尺度不同。**

#### 7.5.3 报告必须怎么写

1. **未来 5–10 年若跨大运，必须分段给结论**，不许合成一句"你适合去东方"。
2. **换运那年标"分段点"**，并写明"此处结论可能翻转，原因是大运改变"。
3. **每段各给一次五行需求向量**，并说明"相比上一段，主需从 __ 变为 __"。
4. 若跨运但结论不变（常见：调候主导的命，寒暖需求不随运变），**也要写明"跨运但结论不变"**——这本身是信息。

#### 7.5.4 三条禁止

| # | 禁止 | 为什么 |
| --- | --- | --- |
| 1 | 用一步大运的喜忌管十年 | 择城的时间尺度就是大运尺度，必须分段 |
| 2 | 因为换运后结论变了，就说"前面算错了" | 换运改结论是正常的，改的是时间条件不是判断 |
| 3 | 把大运五行直接当"喜用" | 大运是"来什么"，喜用是"缺什么"，两者不是一回事 |

> **分级**：7.5.2 的分层法与 7.5.3 的写法为 **CONV（本技能）**；三说并存本身是 **乙（电子文本）**——"用神随运成毁"见于《三命通会》系，但本技能未回原书核，标"待核"。
>
> **这一节的价值**：它解释了择城领域最常见的一种"打脸"——去了某城前几年顺、后几年不顺。可能不是城市变了，是**换运了**。报告里提前标出分段点，就不会把换运的账算到城市头上。

## 八、必须保留竞争假设

**规则：第二步结束时，至少要留下 2 个假设。** 只有一个假设，第三步的校验就变成了"证明我对"，必然附会。

| 来源 | 例子 |
| --- | --- |
| 三视角异判 | 格局法判用官，扶抑法嫌官党煞 → 一判喜金、一判忌金 |
| 强弱临界 | 身强弱在"偏弱/中和"之间，取用随之两可 |
| 调候为急与否 | 冬生但是否已"调候为急"，两解 |
| 格局存疑 | 杂气月令，格成与否两解 |

每个假设写成一张卡：

```
假设 H1：喜水木，忌火土
  依据：__（哪一视角、哪条规则、哪本书哪一章）
  支持点：___
  已知弱点：___
  若为真，应观察到：水木之年顺、火土之年滞
```

最后一句是关键——它是第三步校验的判据，**必须在看事件之前写下来**。

## 九、常见误判清单

| # | 误判 | 后果 | 纠正 |
| --- | --- | --- | --- |
| 1 | 缺什么补什么 | 把忌神当用神，方向完全反 | 先判角色（"缺而不需者不补"） |
| 2 | 数个数定旺衰（三木两火即木旺） | 忽略月令，季节全错 | 得令优先，数量次之 |
| 3 | 有根当身弱 | 漏看得地 | "日干有根，虽失令不作弱论" |
| 4 | 旺极还去克、弱极还去扶 | 反激有害 / 徒劳无功 | 从其强、从其弱 |
| 5 | 把"存在之十神"当"得用之十神" | 身弱财多仍取财 → 反致贫夭 | 取用看"得不得用" |
| 6 | 把调候喜神当用神 | 火无根却执火为用 | 调候只补偏，不独立定用 |
| 7 | 只看日主不看全局 | 忽略格局与流通 | 三视角都跑 |
| 8 | 把"无气"理解为"没有" | 误判某行为真空 | 无气 = 无王相之气（《五行大义》辨正 B-08） |
| 9 | 见冲即凶、见合即吉 | 忽略冲有轻重、合有不合 | 冲看隔位/相邻、有无解救 |
| 10 | 把神煞当主线 | 结论零碎、无法复核 | 神煞只作旁证（见 §10 分歧 2） |
| 11 | 一见到"驿马"就说该迁移 | 把动象当迁移决策 | 驿马只提示"变动倾向"，不指示方向与必要性 |
| **12** | **把"病位"当"药"**（V2.1.3 新增，实测踩到） | **补了等于没补，甚至加重**——因为补的那一方正在被克 | 先问"谁在被克、谁在克它"：**被克的是病位，克它的是药。用神取药。** 见 §4.2 前置两问 |

> **第 12 条是第 1 条（缺什么补什么）的变体**，但更隐蔽：它伪装成"扶抑查表"，看起来完全合规。
> 实测例：庚金亥月，土被木克。查表"弱、食伤多→印绶"给土，取土为主需——**格式全对，结论全反**。
> 土是病位（被木克），金才是药（克木）。这一错会让整份择城报告的方位从"西北"翻到"西南"。

## 十、流派分歧仲裁（择城相关六条）

> 完整十项仲裁见「盘叔子平」元规则 03。此处只取与择城直接相关的六条。

| # | 分歧 | 仲裁 | 在择城问题里的影响 |
| --- | --- | --- | --- |
| 1 | **格局 vs 扶抑**（最根本之争） | 统一为「先辨体后定格」：先定身强弱（扶抑派地基），再定格局用神（格局派主轴）。两法结论相反时，**格局法出主结论，扶抑并列呈现并标注异判** | 直接影响"主需"取值，必须标注是哪一法得出 |
| 2 | **神煞 / 纳音用不用** | 只取象、不独立成断。神煞可用于断事时辅助取象（驿马主奔波、华盖主孤高），**不得用神煞救破格或损成格**，不用纳音定富贵 | **驿马只能提示"有动象"，不能推出"该迁"**——这是本技能禁令第 2 条的来源 |
| 3 | **犯太岁是否必凶** | **推翻"必凶"**。岁运并临、犯岁、伏吟反吟的吉凶只看所并所犯之神与命局用神的生克关系，不看形式本身 | 不得因"流年冲太岁"就判该年不宜迁移 |
| 4 | **财官入库不冲不发** | 以真诠为准：**以透干为取用标准，不以冲库为取用标准**；"冲库开库"只在特定专论中作辅助 | 不得因"今年冲库"就判为发财/破财之年 |
| 5 | **从格月令限定** | 从格要件 = 弃命无根 + 独神势成 + 顺月令盛衰 | 判从格时须看月令节气，不能只凭"日主无根" |
| 6 | **阴阳同生同死** | 从命理约言：阴阳同生同死，且"阳长生有力、阴长生不甚有力" | 用长生判通根力度时取此口径 |

**处理方式**：报告里并列呈现分歧，标注"本技能取哪一套、为什么"。**不许悄悄切换规则以凑出一个结论。**

## 十一、输出接口（交给主流程第二步）

必须产出以下九项，缺一项不算完成：

1. **特殊格判定**：是否成立（成则跳过正格）
2. **强弱判定**：五档之一 + 强在何处
3. **格局判定（五步链条结论，不是两个字）**：按 §4.3 走完
   - ① 格名（月令所成，写明"月令何神当权"）
   - ② 成/不成 **各因何故**（引 §4.4 判据，说明命中了哪一条）
   - ③ 破在何处、救在何处（**破与救都要写**，只写破等于没看完）
   - ④ 清浊与力量对比（有力/无力、清/浊、偏重在哪一方）
   - ⑤ 岁运如何作用（见第 8 项）
   - 层次只写"成格且救应有力 / 成格而救应不足 / 破格有救 / 破而无救"四档，**不硬套上中下**
4. **调候判定**：寒/暖/燥/湿 + 查表所得用神序列 + 是否"调候为急"
5. **三栏对照卡**：格局 / 调候 / 扶抑 各自的用神 + 主裁决
   - 每栏必须注明**是哪一种"用神"义**（见 §0.2.1），三栏不可混称"用神"而不加限定
6. **五行需求向量**：主需 / 次需 / 忌 / 仇 / 存疑
7. **竞争假设 ≥2 个**，每个带"若为真应观察到什么" + **分歧记录**
8. **用神随运分段表**（V1.4 新增，按 §7.5）
   - 列出用户关心的年份区间所跨的大运
   - 每一段写：该运干支 → 对底层需求是补/伤/无干 → 该段的五行需求向量
   - 跨运处必须**分段给向量**，不许一个向量管十年
   - 若判断底层需求不变，也要明写"底层未变，仅强度变化"
9. **术语口径声明**（V1.4 新增）
   - 本次报告中"用神"一词专指哪一路（格局 / 调候 / 扶抑），或三路并列
   - 若引用沈孝瞻与徐乐吾的不同说法，**分别署名**，不合成一句"古人云"

> 第 8、9 两项是 V1.4 因徐子平 Bot 的 `N-04`（文层分栏）与 `N-05`（措辞口径）而加。缺第 8 项，后面的城市建议就只能给一张"终身不变"的向量表，等于把择城问题答成静态问题。
