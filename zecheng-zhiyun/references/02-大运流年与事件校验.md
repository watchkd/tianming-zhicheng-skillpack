# 02 · 大运流年与事件校验

> 本文件是「择城知运」第一步（核对大运）与第三步（用人生关键年份反向校验）的执行依据。
>
> 这一份是整个技能最容易被做坏的地方。做坏了，技能就退化成"先认定喜火，再从人生里挑证据"的圆说机器。所以本文件有一半篇幅在写**禁令**。

## 一、大运排法核对

### 1.1 顺逆

| 年干阴阳 | 性别 | 排法 |
| --- | --- | --- |
| 阳年（甲丙戊庚壬） | 男 | 顺排 |
| 阳年 | 女 | 逆排 |
| 阴年（乙丁己辛癸） | 男 | 逆排 |
| 阴年 | 女 | 顺排 |

### 1.2 起运岁数

从出生时刻数到**下一个节气**（顺排）或**上一个节气**（逆排）的天数：

```
3 天 = 1 岁
1 天 = 4 个月
1 个时辰（2 小时）= 10 天
```

即：天数 ÷ 3 = 岁，余数 × 4 = 月，余数再 × 30 ÷ 3 ≈ 日。交运日期 = 出生日 + 起运岁数对应的日期。

### 1.3 核对清单（第一步必做）

| 检查项 | 不一致时怎么办 |
| --- | --- |
| 四柱是否以立春分年、以节气分月 | 指出，请用户用专业排盘复核，**不擅自改** |
| 顺逆是否与年干阴阳 + 性别匹配 | 指出矛盾，两套都列出，让用户确认 |
| 起运岁数与节气天数是否吻合 | 若差 1 岁以上，说明可能用了不同流派（如按 2 天 = 1 岁），标注流派后继续 |
| 当前年龄落在哪一步大运 | 必须明确到"第几步、干支、起止年份" |
| 是否处于交运前后 1 年内 | 若是，本次分析要标"换运期"，结论稳定性下降 |

> **起运年龄 ≠ 当前大运。** 用户给了性别、起运岁数、当前年龄，仍然必须结合四柱与顺逆排出每一步的干支和交运时间。最稳的做法是让用户直接给专业排盘工具的大运表，本技能负责核对与分析，不自行猜算。用户只给了起运岁数时，可以推算，但必须在报告里注明"大运表为推算所得，请核对"。

## 二、大运与流年的分工

| 层 | 作用 | 时间尺度 | 在择城问题里对应什么 |
| --- | --- | --- | --- |
| 大运 | 十年环境底色，决定"这十年能做什么" | 10 年 | 该不该在这十年里做迁移这类大动作 |
| 流年 | 触发点，决定"哪一年动" | 1 年 | 哪一年适合考察、哪一年适合落地 |
| 命局 | 底盘，决定"能承受多大变动" | 终身 | 迁移是加分还是折腾 |

**判读顺序永远是：命局 → 大运 → 流年。** 反过来（从某个流年反推命局）必然出错。

## 三、把事件变成可校验的数据

### 3.1 六要素

用户说"2015 年我事业特别好"，这句话不能直接用来校验。必须补齐六项：

| 要素 | 问什么 | 为什么要 |
| --- | --- | --- |
| 年份 | 公历哪一年（不确定就说到年即可） | 定位大运流年 |
| 领域 | 事业 / 财富 / 婚恋 / 健康 / 家庭 / 迁移 / 学业 | 决定看哪个十神 |
| 方向 | 进（升、得、成、合）或退（降、失、散、病） | 决定吉凶极性 |
| 强度 | 轻微 / 明显 / 重大转折（1 / 2 / 3） | 决定权重 |
| 具体事 | 一句话说清发生了什么 | 防止"那几年还行"这种模糊记忆 |
| 可控性 | 这件事是自己选择的结果，还是外部发生 | 排除个人努力/时代因素 |

**只给年份不给事件的，不能用于校验。** 必须追问一句"那一年具体发生了什么"，问不到就记为"无效样本"。

### 3.2 领域 → 载体

校验时，要先确定"这件事在命理上由哪个符号承载"，再看该符号在命局中是喜是忌：

| 领域 | 主要载体 | 次要看 |
| --- | --- | --- |
| 事业晋升 / 职务 | 官、杀（体制内偏印） | 印（文书、任命） |
| 创业 / 自立 | 财 + 食伤 | 比劫（合伙） |
| 得财 | 财星得地、财库开 | 食伤生财 |
| 破财 | 比劫夺财、财被冲 | 财星入墓 |
| 婚恋 | 男看财、女看官 | 日支（配偶宫） |
| 生育 | 男看官杀、女看食伤 | 时柱 |
| 疾病 | 忌神冲克日主、日主无根 | 五行偏枯之藏 |
| 迁居 / 远行 | 驿马、地支冲、印（居所） | 大运换柱 |
| 学业 / 考试 | 印星 | 官（名次） |
| 亲丧 | 相应六亲星受冲克 | 年柱/月柱 |

### 3.3 吉凶极性由命局决定，不由事件决定

**关键区分**：某年"财星旺"和某年"得财"是两件事。

- 财星旺 + 身能任财 → 得财
- 财星旺 + 身弱不胜 → 破财、因财致祸

所以校验时不能用"财年"直接当"吉年"，必须看该载体五行在本局中扮演的角色。

## 四、四步校验法

### 第 1 步 · 假设卡片就位

把第二步留下的每个假设写成一句可证伪的话：

```
H1：喜水木，忌火土
   若为真，应观察到：水木之年（或水木得力的年份）偏顺，火土之年偏滞
```

**必须在看事件之前写好。** 顺序颠倒，校验就失效了。

### 第 2 步 · 逐事件对表

对每个有效事件，做 2×2 判定：

| | 事件为吉 | 事件为凶 |
| --- | --- | --- |
| **载体五行 = 假设的喜神** | 支持 +1 | 反对 −1 |
| **载体五行 = 假设的忌神** | 反对 −1 | 支持 +1 |
| **载体与假设无关** | 0 | 0 |

权重 = 强度（1/2/3）× 关联度（直接 1.5 / 间接 1.0 / 存疑 0.5）

**关联度的判法**：该年大运流年干支中，载体五行是"当值"（1.5）还是"仅在地支藏干出现"（1.0）还是"只有旁支关系"（0.5）。

### 第 3 步 · 汇总与判定

```
加权支持率 = 支持分 ÷（支持分 + 反对分）
```

| 支持率 | 有效事件数 | 判定 |
| --- | --- | --- |
| ≥ 70% | ≥ 3 | **保留，置信中高** |
| 50%–70% | ≥ 3 | **保留但存疑**，在报告里明写"证据不足" |
| < 50% | ≥ 3 | **降权**，让位给竞争假设 |
| 任意 | < 3 | **样本不足**，不得据此下结论，只能作旁证 |

**强反例触发复核**：强度 3 + 关联度 1.5 + 无合化解救，只要出现 1 条，无论支持率多高，都必须回头复核该假设，并说明"这条为什么不符合"。

### 第 4 步 · 收敛或保留分歧

**多个假设时逐个算，不要只算一个**（V2.1 补。原版只写了"一个假设算支持率"的流程，第 2 步却要求留 ≥2 个假设，中间是断的）

操作四步：

1. **各假设独立算支持率。** 同一批事件，对每个假设分别做 2×2 判定。
   注意禁令 3（不得一鱼多吃）：若某事件对两个假设都"支持"，只记给支持度更高的那个，另一个记 0，并注明"该事件已计入假设 X"。
2. **看差值**：差 ≥15% → 高者胜出；差 <15% → **并列保留**。
3. **看反例指向哪一方。** 这一步比支持率更有信息量——把每条反例的"为什么不符合"写出来，看这个解释在替哪个假设辩护、又在否定哪个假设。**支持率是计数，反例解释是诊断。**
4. **允许"胜出假设 + 落败假设的修正"。** 常见情形：A 支持率略低，但 B 的反例解释反过来揭示了 A 的边界条件，最终采用"A 的主体 + B 揭示的限制"。

**实测例（V2.1，甲木酉月，身弱官旺）**

| 假设 | 内容 | 支持率 |
| --- | --- | --- |
| A | 木为主需（通关派：水生木、木生火） | 50% |
| B | 水为主需（印化官派） | 62.5% |

差 12.5% < 15% → 按规则应并列。但看反例：2023 癸卯（水年 + 木年）反而生病。这条对 A、B 都不利，真正原因是**癸水制丙**（调候之忌）——而这恰是 B 的软肋：水多则伤丙。

**最终采用**：A 的主体（木为主需）+ B 揭示的限制（水不可多）→ 水定为**次需**，并写入"存疑"栏。

> 若当时只按支持率高低下判，会取 B（水为主需），把"北方水地"排到第一——**结论正好反了**。

**并列保留时不许含糊**：写"两种读法都成立"不够，必须接着写"**这影响的是推荐方位的哪一档**"。例："若取 A，青岛（北·水）降为备选；若取 B，青岛升为首选。本报告取 A，故青岛列备选。"

### 4.1 样本的"鉴别力"先查一遍（V2.1.2 新增，实测踩到）

支持率算完、差值也看了，还可能犯一个更隐蔽的错：**两条样本的五行都成对出现，等于什么都没验。**

**判法**：把每条事件的**载体五行**逐字拆开，看它同时带了几个候选假设的字。

实例（庚金亥月，主需土、次需金、存疑火；H1 主金、H3 主火）：

| 事件 | 干支 | 同时带了谁的字 | 对 H1 | 对 H3 |
| --- | --- | --- | --- | --- |
| 2017 收入涨 | 丁**酉** | 火（丁）＋金（酉） | 顺 ✓ | 顺 ✓ |
| 2022 官非 | **壬寅** | 水（壬）＋木（寅） | 滞 ✓ | 滞 ✓ |

两条样本**双双**同时含 H1 与 H3 的字 → 支持率都 100%、差值 0% → **无鉴别力**。

**这不是"两个假设都成立"，是"这两个假设用这批样本分不开"。** 报告里必须写：

> 样本 2 条，且每条五行成对出现，**分不开"金有功"还是"火有功"**。H1 胜出靠的是多一路文献支撑，不是多一条样本。

**三条处理**：

1. **明写"无鉴别力"**，不许把"2/2"当成"验证通过"。样本数 <3 时，一律只作旁证。
2. **换一条干净样本**：找"纯金年"（庚申/辛酉，无火）或"纯火年"（丙午/丁巳，无金）。**回头问旧事往往问不出来**，因为人记不住纯五行年。
3. **改用前瞻验证点**（比回溯更干净）：直接指定下一个纯五行年做观察，并**事先写下判据**。例：
   > 2026 丙午为纯火年。记录三项：①与上级/官方/合同相关的事顺不顺；②睡眠与心血管/眼的状态；③有无突发口舌。年底回看，两项偏负 → 火为忌，南方降级。

> 前瞻验证的好处：**判据在看结果之前就定下了，防附会七条里的第 1 条管不到它**（它不是回忆，是记录）。

**这一条为什么重要**：择城结论最容易被"火该不该补"这类单项翻盘，而这一项恰恰最难用旧事验证。**承认分不开，比强行分出胜负诚实，也更有用——因为它给出了下一步该看什么。**

**全部假设都不成立** → 说明第二步的取用有问题，退回重判一次（**只重判一次**，不许无限重来）。

## 五、防附会七条禁令

这七条是本技能不可越过的底线。

| # | 禁令 | 违反后的表现 |
| --- | --- | --- |
| 1 | **不得先看结论再回忆事件** | 用户已读过分析再补述"那几年确实顺"，该样本只能记 0.5 权重，并标注"回忆受污染" |
| 2 | **不得事后引入新规则救假设** | "这一年不符，是因为流年与命局暗合"——除非该合化关系在事前规则中有独立依据，否则禁止 |
| 3 | **不得一鱼多吃** | 同一个事件不能同时支持两个假设 |
| 4 | **不得只记顺、不记逆** | 反例必须逐条列出，哪怕只有一条 |
| 5 | **不得把"没出事"当"吉"** | 平淡之年是中性样本，不计分 |
| 6 | **不得把外部大势当命理应验** | 行业周期、疫情、家庭变故等外部因素要单独标注，可降权至 0.5 |
| 7 | **不得用神煞救场** | 不得因某年不符就临时搬出贵人、华盖、羊刃来解释 |

## 六、不吻合案例的处理

不吻合是常态，不是失败。处理方式：

| 情形 | 处理 |
| --- | --- |
| 单条不符，其余吻合 | 记为"离群点"，不改变结论，但写进报告 |
| 连续 2–3 条同向不符 | 触发假设复核，考虑是否为"次需"或"调候"主导 |
| 重大事件完全反向 | 该假设降权，启用竞争假设 |
| 全都不符 | 退回第二步重判，并明确告诉用户"原判断不成立" |

**必须在报告里写一句**：本次校验有几个有效样本、支持率多少、哪些事件不符。不许只写"与过往经历吻合"。

## 七、未来 5–10 年逐年推演

校验通过后，才做未来推演。逐年输出下表：

| 年份 | 流年干支 | 所处大运 | 流年五行对命局 | 相对吉凶（依已校验喜忌） | 动象（迁移相关） |
| --- | --- | --- | --- | --- | --- |
| 2027 | 丁未 | 第 X 步 甲子 | 火土，忌神当值 | 偏滞 | 无 |
| 2028 | 戊申 | 同上 | 土金，申冲寅（驿马） | 平 | **有动象** |

### 7.1 动象怎么判（只作提示，不作命令）

| 信号 | 含义 | 权重 |
| --- | --- | --- |
| 大运换柱前后 1 年 | 环境切换窗口，最典型的"换城市"应期 | 高 |
| 流年冲命局驿马（申子辰马在寅等） | 有变动倾向 | 中 |
| 流年与日支/年支相冲 | 居所、根基动摇 | 中 |
| 印星流年 | 置产、安家、文书 | 中 |
| 驿马逢合 | 想动而动不成 | 提示"阻力" |

**铁律：动象只说明"这一年容易发生变动"，不说明"应该变动"，更不指示方向。** 方向必须来自喜用校验 + 方位计算，不能从冲合里推。

### 7.2 窗口分级

| 级别 | 条件 | 建议动作 |
| --- | --- | --- |
| A 考察窗 | 喜神年 + 有动象 | 实地考察、面试、试住 |
| B 落地窗 | 喜神年 + 大运换柱 + 命局能承 | 可落实迁移计划 |
| C 观察窗 | 中性年 | 收集信息，不做决定 |
| D 静守窗 | 忌神年当值 | 不宜裸辞式迁移；可在原地准备 |
| E 不明窗 | 岁运并临、天克地冲且无法判吉凶 | 只提示"变动概率高"，不给方向 |

## 八、输出接口（交给主流程第三步）

必须产出：

1. **有效样本表**：年份 / 领域 / 方向 / 强度 / 载体 / 支持或反对 / 权重
2. **加权支持率**：每个假设一个数
3. **判定**：保留 / 存疑 / 降权 / 推翻
4. **反例清单**：一条也不能省
5. **污染标注**：哪些样本是"看过结论后补述"的
6. **最终采用的喜忌**：主需 / 次需 / 忌，与第二步的差异及原因
