## 零、先纠正四个常见误解

在读下面的规则之前，必须先说清这篇到底在讲什么。不然后面的表会被用错。

### 误解一：它讲的是"出生时地"，不是"迁居目的地"

原文通篇说的是"**生**于某州"——"兖、青人富贵无虞""冀、雍生者贫寒"。**没有一个字讲迁居。**

所以：把这篇直接当"该搬去哪个州"的依据，是**本技能的外推，不是原文主张**。外推的合理性在于"同气相求"（地域之气与日主同气则得地），但这是推演，报告里必须标。

### 误解二：它不是"城市属某五行"的分类表

原文的句式是"**某日主五行 × 生于某州 → 得地/失地**"，不是"某州属某五行"。

要得到"州属某行"，必须**反读**：木生于兖青为得地 → 兖青之气与木同。这一步反读是合理的，但**原文没这么说**，属推演（见 §3）。

### 误解三：它的核心主张恰恰是"别机械套"

> 原文："今之谈命者，但知论阴阳五行而不知兼论方隅与昼夜阴晴，所以有年日月时同而贵贱寿夭迥异，便谓五行无据，启世人不信命之疑，亦诬点。"

> 原文："九州分疆，风气异宜，阴晴寒暖，理难一律。人禀天地灵气以生一时，得气各自不同，所以贵贱寿夭难以八字拘也。"

> 原文："生克制化，抑扬轻重，妙在识其通变，**不可执一论也**。"

**这三句是整篇的总纲**，也是本项目"不可执一而论"一语的出处。作者本人的立场是：八字相同而命不同，正因为地域与昼夜阴晴不同。所以他把"地域"当成一个**必须加进来、但也不能机械套用**的维度。

> 这对本技能是个警告：**它反对的正是"某地属某行，所以适合你"这种单线推论。** 下面的规则表只能用来看"哪种组合下哪个州吉/凶"，不能简化成一个城市五行标签。

### 误解四（V1.3 新增，重要）：它用的是《禹贡》九州，不是《周礼》九州

这条是 V1.2 的判断失误，必须改正。

古代"九州"至少有三套：

| 系统 | 九州 | 有无徐、梁 | 有无幽、并、营 |
| --- | --- | --- | --- |
| **《尚书·禹贡》** | 冀、兖、青、徐、扬、荆、豫、梁、雍 | ✅ 有 | ❌ 无 |
| 《周礼·夏官·职方氏》 | 扬、荆、豫、青、兖、雍、幽、冀、并 | ❌ 无 | ✅ 有幽、并 |
| 《尔雅·释地》 | 冀、豫、雍、荆、扬、兖、徐、幽、营 | ✅ 有徐 | ✅ 有幽、营 |

**《三命通会》原文列的是：冀、青、兖、徐、扬、荆、梁、雍、豫——九者齐备，且正含徐、梁，正无幽、并、营。这是标准的《禹贡》系统。**

所以正确的推论是：

| 城市 | V1.2 的错误结论 | **V1.3 的正确结论** |
| --- | --- | --- |
| 北京 | "幽州不在九州内，无甲级依据" | **禹贡属冀州 → 有甲级（水）**；但《周礼》作幽州，属两系统之争 |
| 太原 | "并州不在九州内，无甲级依据" | **禹贡属冀州 → 有甲级（水）**（原文"既修太原"即冀州境）；《周礼》作并州 |
| 昆明、贵阳 | "益州不在九州内，无甲级依据" | **禹贡梁州西境至黑水 → 有甲级（金）**；汉置益州，属两系统之争 |
| 哈尔滨、长春、乌鲁木齐、拉萨 | — | **确实在九州之外**，无甲级（这才是真正的"无依据"） |

> **V1.2 错在哪**：把"幽、并、益不在这九个州名里"正确地说出来了，却错推成"这些城市没有甲级依据"。实际上城市可以归入冀州或梁州——问题只是**归入哪一州有争议**，不是**没有州可归**。
>
> **修正后的口径**：城市分三档——**定**（归属无争议）／**议**（两系统之争，两个候选并列）／**外**（九州之外，真的无依据）。三档写进 `scripts/zhou.json`，由脚本判定，不靠人记。

## 一、核心配属表（全篇最硬的五条）

这是全篇唯一成体系的配属，其余都是逐格断语。

| 日主五行 | 干支 | 得地之州 | 得时之令 |
| --- | --- | --- | --- |
| 木 | 甲、乙、寅、卯 | **兖、青** | 春 |
| 火 | 丙、丁、巳、午 | **徐、扬** | 夏 |
| 土 | 戊、己、辰、戌、丑、未 | **豫** | 四季月（辰戌丑未） |
| 金 | 庚、辛、申、酉 | **荆、梁** | 秋、冬 |
| 水 | 壬、癸、亥、子 | **冀、雍** | 冬 |

> 原文："且以甲乙寅卯属木，生于兖、青为得地，春令为得时。丙丁巳午属火，生于徐、扬为得地，夏令为得时。戊己辰戌丑未属土，生于豫州为得地，四季月为得时。庚辛申酉属金，生于荆梁为得地，秋冬为得时。壬癸亥子属水，生于冀、雍为得地，冬令为得时。"

**注意两处不对称**：
1. **金得时在"秋冬"两季**，其余四行都只给一季。
2. **土得时在"四季月"**（辰戌丑未四个月），不是"长夏"一季。

### 2.1 反读的两处风险（必须知道）

**风险一：原文未说明理由。** 为什么荆梁属金？为什么雍州属水？原文只给结论，不给论证。可能是星野、可能是山川物产、可能是别的体系，但**原文没说**。

所以：**不许替它补理由**。报告里写"依《三命通会》卷四得地条，荆梁与金同气"，不要写"因为荆梁产金"之类的话——那是编造。

**风险二：一州之内气候差异极大。** 扬州含江浙闽赣，从北亚热带到南亚热带；梁州含川西高原与川东盆地。**州是文化政区，不是气候区**，用它判"地域之气"必然粗糙。

## 三、与八卦方位五行的冲突（本篇最重要的发现）

把 §2 的州五行，按各州的地理方位摆到八方位上，会与《五行大义》的方位五行正面冲突：

| 方位 | 八卦方位五行（五行大义） | 该方位所含州 → 三命通会州五行 | 是否一致 |
| --- | --- | --- | --- |
| 正东 | 木（震） | 青（木）、兖（木） | ✅ 一致 |
| 东南 | 木（巽） | 徐（**火**） | ❌ **冲突** |
| 正南 | 火（离） | 扬（火）、荆（**金**） | ⚠️ 半冲突（扬一致，荆冲突） |
| 西南 | 土（坤） | 梁（**金**） | ❌ **冲突** |
| 正西 | 金（兑） | （梁含陕南，偏金） | ✅ 大致一致 |
| 西北 | 金（乾） | 雍（**水**） | ❌ **冲突** |
| 正北 | 水（坎） | 冀（水） | ✅ 一致 |
| 东北 | 土（艮） | （冀含内蒙，偏水） | ⚠️ 半冲突 |
| 中央 | 土 | 豫（土） | ✅ 一致 |

**四处硬冲突：东南、西南、西北，加半个正南。**

### 3.1 怎么处理 —— 不许调和，只许分用

这两套不是"一个对一个错"，而是**回答两个不同问题**：

| | 八卦方位五行 | 三命通会州五行 |
| --- | --- | --- |
| 回答什么 | 目的地相对**你现在的位置**在哪个方向 | 这片**地域本身**与哪一行同气 |
| 参照系 | 相对（以现居城市为原点） | 绝对（与你在哪无关） |
| 依据 | 《五行大义·论八卦八风》"乾兑金、坎水、震巽木、离火、坤艮土" | 《三命通会》卷四"得地"条 |
| 用法 | 定"往哪个方向走" | 定"哪片地方的气与我的日主相合" |
| 置信 | 高（几何 + 原文直证） | 中（原文直证，但反读是推演） |

**处理规则（写进 03 号文件 §8，此处为执行口径）**：

1. **两栏分列，永不合并。** 报告里"方位"栏写八卦方位五行，"地域"栏写州五行。
2. **冲突时并列呈现，并说明这是两套系统的分歧**，不是某一方错了。
3. **不许为了让结论好看而挑一套用。** 若两套同向，可以写"两说同向，可信度较高"；若相反，必须写"两说相反"。
4. **优先顺序**：问"往哪个方向"用方位；问"这片地方的气合不合我"用州五行。问题不同，优先不同。

### 3.2 一个真实的例子

从**上海**出发去**成都**：

- 方位：272°，正西·兑·**金**（几何计算，高置信）
- 地域：成都属梁州，梁州与**金**同气（三命通会得地条）
- **两说同向** → 可以写"方位与地域皆属金，同向"

从**上海**出发去**广州**：

- 方位：224°，西南·坤·**土**（几何计算）
- 地域：广州属扬州，扬州与**火**同气（三命通会）
- 八卦方位说西南属土，但扬州在东南沿海、三命通会说火
- **两说冲突** → 必须写"方位属土，地域属火，两说相反"

> 这就是为什么"广州在南方所以属火"这句话既对又错：**按州五行对（扬州=火），按八方位错（上海看广州是西南属土）。** 两个答案各自成立，取决于你问的是哪个问题。

### 4.6 得地条 vs 逐格断语：自洽度审计（乙级，V1.3 新增）

§一 的得地条说"某行生于某州为得地"（=吉）。§四 的逐格断语里，同一个州却时吉时凶。这两套能不能对上？逐条数一遍：

| 五行 | 得地州 | 该州在逐格表中出现的次数 | 吉 / 凶 | 自洽度 | 结论 |
| --- | --- | --- | --- | --- | --- |
| 土 | 豫 | 4 | 4 / 0 | ★★★ 高 | 豫州**从未被判凶**，与"土生于豫为得地"完全吻合 |
| 金 | 荆梁 | 6 | 6 / 0 | ★★★ 高 | 荆梁**从未被判凶**，与"金生于荆梁为得地"完全吻合 |
| 木 | 兖青 | 4 | 3 / 1 | ★★ 中 | 三吉一凶（子丑月"有陨自夭"）——极寒时同气反成负担 |
| 火 | 徐扬 | 5 | 3 / 2 | ★ 低 | 火旺时（五六月、秋初）徐扬反凶，火上加火 |
| 水 | 冀雍 | 3 | 1 / 2 | ★ 低 | 冬月一吉一凶；另有子丑月"孤贫"——水寒之地忌再寒 |

**怎么用这张表**：

1. **土、金的得地条可以直接用**：逐格断语从不与它冲突。
2. **木的得地条要加条件**：只在非极寒月令成立（子丑月例外）。
3. **火、水的得地条不能单独用**：必须先看当期是"该行过旺"还是"该行不足"。火旺时徐扬是灾地，火衰时徐扬才是福地；水同理，冀雍在冬月既是堤防也是冰窖。

> **这不是原文的观点，是本技能对原文的统计核对。** 但它解释了一件事：为什么 §一 那五条看起来像"绝对配属"，用起来却处处要加条件——**因为得地条讲的是"地利"，逐格断语讲的是"月令 + 地利 + 昼夜"三者叠加**。地利被月令压倒时，得地条就失效了。
>
> 所以：**得地条是底分，不是结论。** 报告里写"成都属梁州，与金同气"，这是底分；能不能用，要看 §4 的月令格与 01 号文件的喜用。

### 6.2 州吉凶 → 喜用：转换算法（丙级，本技能自建）

V1.2 只写了"必须转换"，没给算法——等于把最难的一步留给临场发挥。V1.3 补上。

**问题在哪**：原文的吉凶是按"**日主五行**在某州某月是否得宜"判的；本技能要的是"**该州五行**是否补命局所缺"。两个问法不同，结论可以完全相反。

例：甲木日主生三月，原文"荆梁凶"（金克木）。但若这命局木极旺、正需金修削（01 号文件的"身旺喜克"或专旺格顺其气势），则荆梁（金）恰恰是有利之地。**照抄原文就把结论弄反了。**

**算法**：设 S = 该州五行，D = 日主五行，向量 = 01 号文件定出的 {主需, 次需, 忌, 仇}。

> **查表之前先过四问**（V2.1 新增三问，V2.1.2 补第四问）：
>
> 1. **S 到底落在向量的哪一位？** 主需、次需、忌、仇四者只能选一个。**次需不是"小一点的主需"，它在表里是另一行、另一条规则。**
> 2. **原文说的是吉还是凶？** 逐字看，不要凭"这个州五行对我有利"倒推原文。
> 3. **选中的那一行，允许我把它判成什么？** 只有该行明写的结论才能用。**不许跨行借结论。**
> 4. **这条断语带条件吗？条件成立吗？**（V2.1.2 补，实测踩到）
>    原文大量断语是"**条件 + 结论**"结构，条件不成立时整条不适用，**不能只取结论、丢掉条件**。
>
>    实例（庚金生亥月，论金·初冬）：凶州"徐扬（**干支无土日生者**贫夭）"、断语"**夜生**者孤寒"。
>    若本命干支有土、又是昼生，则"贫夭""孤寒"两个条件**都不成立**，
>    → 该格对本命只剩"见火则为伤残"（负）与"遇土则衣禄丰足"（正）两句有效。
>    **若照抄"徐扬凶"整句，会凭空多背一条不属于本命的凶断。**
>
> 最容易犯的错：S ∈ 次需，心里想"次需也是我需要的"，于是按情形 1（主需）判成"有利"。**这是错的。** 次需在情形 2，原文凶时只能降到"中性偏不利"。

| # | 情形 | 原文吉凶怎么处理 | 最终结论 |
| --- | --- | --- | --- |
| 1 | **S ∈ 主需** | **反向适用**：原文说凶 → 实为有利；原文说吉 → 加强 | 以喜用为准，明确写"与原文相反" |
| 2 | **S ∈ 次需** | 原文吉 → 保留；**原文凶 → 降为"中性偏不利"** | 以喜用为准，弱化原文。**次需 ≠ 主需，原文凶时不许升格为有利** |
| 3 | **S ∈ 忌** | 原文凶 → 同向加强；原文吉 → **降为存疑**（按日主吉 ≠ 按命局吉） | 以喜用为准 |
| 4 | **S ∈ 仇** | 同忌，且优先级更高 | 以喜用为准 |
| 5 | **S = D（同气）** | 看 D 过旺还是不足：过旺 → 同气为忌，原文吉不可信；不足 → 同气为喜 | 这正是"子丑月同气反夭"的道理（§4.0 反直觉处①） |
| 6 | **S 不在向量任何位置** | **原文吉凶不适用**，只作背景信息，不进结论 | 该州对本命无实质作用，按中性处理 |
| 7 | **S ∈ 存疑** | 原文吉凶**只作旁证**，不单独定结论；原文凶时，作为"该行不宜多补"的一条证据 | 中性处理。**存疑格不能当主需格用**（V2.1 补：向量有五项，原表只覆盖四项） |

**两条必须知道的推论**：

1. **专旺格 / 从格，与原文必然相反。** 原文默认"日主宜中和"，专旺格却要"顺其旺势"。所以遇到专旺、从格，情形 1 与情形 5 会高频触发——**不是原文错了，是它不适用于这类命**。
2. **普通正格里，两者多数同向。** 所以"原文吉"和"喜用有利"经常一致；一旦不一致，**先回 01 号文件复核自己的喜用判断，再怀疑原文**。不许一遇冲突就说"古籍不适用"——那是偷懒。

**输出必须写成两句并列**，不许合成一句：

```
【本命交叉】原文：甲木生三月，荆梁凶（逢金伐木）
            喜用：本局木旺需金修削，金为主需
            → 两者相反。采喜用：成都（梁州·金）对本命有利。
            注：此结论与"日主直觉"相反，因命局木旺，不顺原文"宜中和"的前提。
```

**次需格的正误对照**（V2.1 补，实测最容易错的一格）：

```
【错】原文：甲木生八九月，冀雍凶（见水漂流尤忌）
      喜用：本局喜水为印
      → 判"与原文相反，水对我有利"。            ← 错在把次需当主需

【对】原文：甲木生八九月，冀雍凶（见水漂流尤忌）
      喜用：本局喜水为印，但水在**次需**（主需是木）
      → 情形 2：原文凶 → 降为"中性偏不利"，不打满分。
        水可用，但不宜再靠地域猛补。
```

> 差别不在格式，在结论：前者会把"北方水地"排到第一，后者只把它排到中游。**同一条原文，跨一行，城市排序就变了。**

> **一句总结**：原文判"你的日主在这地方舒不舒服"，本技能判"这地方的气补不补你的缺"。**舒服 ≠ 补。** 两句都要写出来，让用户自己看见分歧在哪。

## 七、在择城问题里怎么用（三步）

### 第 1 步 · 查本命对应州

```
输入：日主天干 + 出生月支
↓
查 §4 对应五行的表，定位月令段
↓
读出该格：哪些州吉、哪些州凶、关键条件是什么
```

例：甲木日主，生三月（辰）→ 查 §4.1 三月行 → 吉：徐扬（富贵）；凶：荆梁（逢金伐木则凶）；条件：喜火土忌金水。

### 第 2 步 · 候选城市 → 州（乙级映射）

按 03 号文件 §5 的州—省域表，把候选城市归到州。归不进去的（如境外、州界模糊带）**标"无州属"**，不硬塞。

### 第 3 步 · 三重交叉

| 交叉项 | 若一致 | 若冲突 |
| --- | --- | --- |
| 州吉凶（本节）× 方位五行（06 号文件） | 置信提升一档 | 两说并列，不合并 |
| 州吉凶 × 地域地理取象（03 §6，丙级） | 置信提升一档 | 以甲级（本节）为主，丙级降为补充 |
| 州吉凶 × 现实条件（产业、成本、家庭） | 强推荐 | 降为备选，并说明"命理同向但现实不符" |

### 输出示例

```
城市：成都
【方位】相对上海 272°，正西·兑·金 —— 甲级，置信高
【地域】梁州 → 与金同气（三命通会卷四得地条）—— 甲级（反读为推演），置信中
        本命：甲木生三月，查论木·三月 → 吉徐扬、凶荆梁（逢金伐木）
        → 成都（梁州）落在"凶"侧
【两说关系】方位金、地域金，同向；但与本命（木）相克
【结论】方位与地域皆属金，对本命甲木不利。若命局喜金则另论（见校验结果）。
```

> 注意最后一句：**州吉凶是按"日主五行"判的，不是按"喜用"判的。** 若本命虽为甲木但喜金（如木旺需金修削），则"荆梁凶"这条不适用。**转换算法见 §6.2**，不要临场发挥。
