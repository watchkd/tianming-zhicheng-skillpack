## 零、先把三件事分开

择城问题里，最容易出错的是把三个不同层面的东西混成一个"这城市属什么"的结论。

| # | 层面 | 定义 | 参照系 | 能不能算 |
| --- | --- | --- | --- | --- |
| A | **方位** | 目标城市相对当前城市的朝向 | **相对**（以当前城市为太极点） | 能，纯几何，用 `scripts/fangwei.py` |
| B | **地域五行** | 这座城市所在之地本身的五行属性 | **绝对**（与你在哪无关） | 只能分级判定，置信度有限 |
| C | **城市气质** | "深圳属火""上海属水"这类流行说法 | 无参照系 | 不能算，只能辨析 |

**A 与 B 必须分别呈现，不许合并。** 一座城市相对你属南方（A=火），它的地域五行完全可能是金（B=金）。这时报告要写：

> 方位：正南，属火 —— 依据：经纬度计算 + 《五行大义》方位五行，几何事实，置信高
> 地域五行：荆州，属金 —— 依据：《三命通会》卷四得地条（甲级）+ 城市归属州（乙级），置信中
> 两说相反，不合并。若命局喜火，则方位有利而地域不利；若喜金，则相反。

**V1.2 之前这里只能写"丙级地理推演，置信低"。现在能写州五行了——但有据不等于精确，详见 §5.1、§5.2、§9.4。**

## 一、判定的四级依据

| 级 | 名称 | 内容 | 可溯源 | 可用性 |
| --- | --- | --- | --- | --- |
| **甲** | 古籍分野 | 二十八宿 / 十二次 / 州国 的地域对应；**州 → 五行的直接配属**（《三命通会》卷四·得地条） | 可（书名 + 篇名） | 州五行可落到"州"级；再往城市落就掉到乙级 |
| **乙** | 州国 → 现代地域 | 把古代九州十二国映射到今天的省域 | 部分是推演 | 可作粗筛，必须标注为推演 |
| **丙** | 地理事实推演 | 气候、地形、水系、日照、植被的五行取象 | 事实可查，取象是推演 | 主力依据，可证伪 |
| **丁** | 民间说法 | "某城属某行"的流行说法 | 无 | **禁用**，只能拿来辨析 |

**判定顺序：先看甲，甲不足看乙，乙不足看丙，丁永不作为依据。**

> **V1.2 说明**：甲级现在有两类东西——① 分野（宿/次/国 → 地），只给方位与州名，**不给五行**；② 州五行（《三命通会》得地条：木兖青、火徐扬、土豫、金荆梁、水冀雍），**直接给五行**。判地域五行走第 ②，判方位走第 ①。两者不许互相印证，因为它们在四处结论相反（见 §9.4）。

### 5.1 城市归属分三档：定 / 议 / 外（V1.3 修正）

**V1.2 曾写"幽、并、益三州不在九州内，故北京、太原、昆明无甲级依据"。这是错的**——城市可以归入冀州或梁州，问题只是**归入哪一州有争议**，不是**没有州可归**。详见 `03a` §零 误解四。

修正后分三档，机器可读版在 `scripts/zhou.json`：

| 档 | 含义 | 典型城市 | 报告怎么写 |
| --- | --- | --- | --- |
| **定** | 禹贡归属明确，单州，无重大异说 | 上海、杭州、成都、西安、济南、青岛、武汉、长沙 | 直接给州五行，标"甲级州五行 + 乙级归属" |
| **议** | 两系统之争，或两州交界，有两个候选 | **北京、天津**（冀/幽）、**太原、大同**（冀/并）、**昆明、贵阳**（梁/益）、**沈阳、大连**（冀/幽）、合肥（扬/豫）、安阳（冀/豫）、信阳（荆/豫）、盐城（徐/扬） | **两个候选都写**，说明争议来源，不替用户选 |
| **外** | 确在九州之外，无对应州 | 哈尔滨、长春、吉林、齐齐哈尔、大庆、牡丹江（肃慎/扶余故地）、乌鲁木齐（西域）、拉萨（吐蕃）、全部境外城市 | 如实写"九州之外，地域五行无甲级依据"，只走丙级 |

### 5.2 全国覆盖与"批量推演"（V2.0）

`scripts/cities.json` 现为 **3283 条（中国 3231 + 海外 52）**，**覆盖全国 2840 个县级行政区 + 369 个地级市（含直辖市、特别行政区）+ 22 个台湾县市**。

来源：阿里云 DataV.GeoAtlas 行政区划边界（2026-10 抓取），坐标为行政区中心点。生成脚本 `_src/geo/crawl.py` + `_src/geo/build_full.py`，幂等可重跑。

**关键区别：州归属分两种来源，报告里必须区分。**

| 源 | 条数 | 含义 | 怎么用 |
| --- | --- | --- | --- |
| **人工核定** | 227 | 逐城核对过，州与档都经过判断 | 可直接用 |
| **批量推演** | 3056 | 按「省规则 + 市例外 + 区县继承所属市」推导 | **可作参考，不得当甲级依据引用**；报告须注明"此条为批量推演" |

批量推演的推导规则（写在这里，便于复核）：

1. **省规则**：全省落在同一州的，按省定（如四川→梁州、湖北→荆州）；跨州或有两系统之争的省，整省标"议"并给两候选（如山西→冀/并、贵州→梁/益）。
2. **市例外**：省会与地级市按实际地理位置单独判定（如江苏徐州→徐州、山东青岛→青州、河南南阳→荆州）。
3. **区县继承**：县级行政区一律继承其所属地级市的州与档。
4. **台湾 22 县市**：数据源无下级区划，按县市政府驻地坐标人工补录，州归属走省规则（台湾省 → 扬州 / 议）。市与县同名的（新竹市/新竹县、嘉义市/嘉义县）保留后缀区分；金门、连江与福建同名县并存，查询时按「市名+区名」或全名消歧。

> **为什么不一城一城手工核**：2840 个县级单位手工核必然出错且无法复核。**批量生成 + 明确标注来源**，比手挑 200 个城市然后声称"覆盖全国"诚实得多。
>
> **这条规矩的底线**：`※批量推演` 的标记会出现在脚本输出里。报告里引用批量推演的州归属时，**必须写明"按所属市推演"**，不许写成"据《三命通会》该地属某州"——州五行是甲级，具体这个县属哪个州不是。

**仍有三条边界：**

1. **台湾 22 县市为人工补录**（数据源无台湾下级区划，坐标为县市政府驻地近似值）。其中台北、高雄、台中、台南、新竹市、桃园 6 座为人工核定，其余 16 座为批量推演。
2. **海外 52 座**，主要目的地，非全量。
3. **区级精度**：同城的区现在有独立条目，能算区与区之间的方位，但**精度只到区中心，不到街道**（`06` §5.5）。

**三档的处理差异（不许混用）**：

1. **定**：可以下结论。
2. **议**：**不许择一**。写"按《禹贡》属冀州（水），按《周礼》职方氏为幽州（无对应五行）——两说并列"。
3. **外**：不许拿邻近州硬套。北京**可以**归冀州，因为禹贡确实含它；但哈尔滨不行，禹贡不含东北腹地。

> **V1.2 与 V1.3 的差别，用一句话说**：V1.2 把"州名不在列表里"误当成"地方没有州"，于是把北京、太原判成了无依据。实际上《禹贡》冀州很大，北京太原都在里面。**真正的"无依据"只有东北腹地、西域、吐蕃与境外。**

### 5.3 乙级映射的三重不确定性

① 古今政区边界差别极大；② 一州之内气候差异极大（扬州从苏南到岭南）；③ 城市多在新开发的交通节点上，与古代州治无继承关系。

所以：**州的五行是甲级，城市落在哪个州是乙级。** 整条链的置信度取最低那一环——**乙级**；"议"档再降一档。

## 六、丙级：地理事实推演（主力依据）

这一层不依赖分野，直接把城市的**可观测特征**取象为五行。取象传统本身有依据（《五行大义》全书就是取象法），但"某城市属某行"这一步没有古籍条文，属于丙级。

### 6.1 判据表

| 观测特征 | 取象 | 五行倾向 | 理由 |
| --- | --- | --- | --- |
| 冬季严寒、年均温低 | 寒、藏、润下 | **水** | 水主寒、主藏 |
| 湿热、日照强、纬度低 | 炎上、暑 | **火** | 火主炎上、主暑 |
| 干燥少雨、大陆性气候 | 燥、刚 | **火土** | 燥属火，土主燥 |
| 沿海、沿大江大湖、水系密 | 润下、流通 | **水** | 水主润下、主流通 |
| 山地、高原、岩石裸露 | 坚刚、高峻 | **土金** | 土主高厚，金主坚刚 |
| 平原沃土、农业区 | 持载、含容 | **土** | 土主稼穑、主承载 |
| 森林覆盖高、植被繁茂 | 生发、条达 | **木** | 木主生发条达 |
| 风大、季风通道 | 动、散 | **木** | 《五行大义》六气配五行取服虔说："阳与风 → 木"，"风自是阴阳之气"，取巽木之义 |
| 港口、贸易、流动人口 | 流通、不息 | **水** | 水主流通 |
| 重工业、冶炼、机械 | 坚刚、裁断 | **金** | 金主坚刚、主裁断 |
| 金融、信息、流通服务 | 流通、明睿 | **水** | 水主智、主流通 |
| 文化、教育、出版 | 文、生发 | **木** | 木主生发、主仁 |

### 6.2 丙级的证据要求

每一条丙级判定必须写清三件事，缺一条就不成立：

1. **事实**：具体是什么（年均温、年降水、地形、水系、主导产业）
2. **取象**：这个事实按哪一条判据取象
3. **同向性**：至少两条独立判据指向同一行，才可下结论

**只有一条判据的，写"偏某行（弱判断）"，不写"属某行"。**

## 七、丁级：民间说法（禁用清单）

下面这些说法流传很广，但都没有出处。**本技能不得用它们作判定依据**，只能在用户主动提及时加以辨析。

| 流行说法 | 问题 | 处理 |
| --- | --- | --- |
| "深圳属火，因为年轻、快" | "年轻、快"是城市气质，不是地理事实；也无古籍条文 | 辨析：可从"湿热气候"取火、从"沿海港口"取水，两说并存 |
| "上海属水，因为在海边" | 海边是水，但上海的产业与金融也取水，双重计入会放大 | 只算一次，且标丙级 |
| "北京属土，因为是帝都" | "帝都"是政治属性，不是五行判据 | 不用；可从"北方寒燥"取水、"燕山地形"取土 |
| "某城按省份定五行" | 一省常跨两三州，且省内气候差异大 | 不用省级一刀切 |
| "按城市名笔画/字义定五行" | 属姓名学，与本技能无关 | 明确拒绝 |

## 八、融合判定规则（核心算法）

对每一座候选城市，按下面的判定树走一遍。**查州这一步不要手工做，跑脚本**：

```bash
python scripts/fangwei.py --from <现居> --to <候选...> --card
```

```
第 1 问：查 zhou.json，这座城市是"定"、"议"还是"外"？
  ├─ 定 → 州五行直接查 03a §2（甲级）
  │        城市→州归属是乙级推演 → 整链置信"中"
  │
  ├─ 议 → 两个候选州都取，州五行各查 03a §2
  │        ├─ 两候选五行相同 → 可当"定"用，但注明归属有争议
  │        ├─ 一有一无（如冀州水 / 幽州无）→ 只呈现有的那一方，注明另一说无依据
  │        └─ 两候选五行不同 → **不许择一**，两说并列，置信"中偏低"
  │
  └─ 外 → 无甲级州五行，转第 2 问（只走丙级）

第 2 问：丙级判据是否 ≥2 条同向？
  ├─ 是 → 得"偏某行"。记：丙级结论 + 置信"中"
  └─ 否 → 记"丙级不足"，最多写"弱判断"

第 3 问：甲级州五行与丙级是否同向？
  ├─ 同向 → 置信提升一档，可写入主推理由
  ├─ 冲突 → 两说并列呈现，置信"低"，不得合并成一个结论
  └─ 一方缺 → 只呈现有的那一方，置信"中/低"

第 4 问：只有丁级？
  └─ 是 → 不判定。报告写"该城市地域五行缺乏可依据的判断"，只给方位结论
```

### 8.1 甲级怎么变成五行（V1.2 已改，V1.3 加"议"分支）

**旧做法（V1.0–V1.1）**：`城市 → 州 → 州的方位 → 方位五行`，两跳，且与《五行大义》的方位五行绑定。

**新做法（V1.2 起）**：`城市 → 州 → 查 03a §2 的州五行`，**一跳**。

例：成都 → 梁州 → **金**（《三命通会》卷四"庚辛申酉属金，生于荆梁为得地"）。

**这个改动带来三件事**：

1. **置信提升**：从"甲级但间接"变成"甲级直接"（州五行）+ 乙级（城市归属州）。
2. **与方位五行解耦**：州五行不再由方位推出，所以当"方位属金"而"州属水"时，两者是**真正独立的两套结论**，不是同一套算了两遍。这正是 §3.1 要求的"两栏分列"的物理基础。
3. **V1.3 补充**：归属本身可能多解（冀/幽），此时不是"算错"，是**史料本身有两套**。脚本会输出两个候选，"两栏关系"一栏会标"一同一异"或"同向（另一候选无甲级）"。

> **但仍然不许合并。** 方位是"相对你的朝向"，州五行是"这片地的气"，两回事。

### 8.2 三档的具体处置

| 情形 | 处理 |
| --- | --- |
| **定**（如上海→扬州） | 直接给结论，标"甲级州五行 + 乙级归属" |
| **议**（如北京→冀/幽） | **两个候选都写**，说明争议来源（禹贡 vs 周礼），不替用户选 |
| **外**（哈尔滨、乌鲁木齐、拉萨、境外） | 只用丙级（气候、地形、水系、产业）；报告明写"九州之外，无古籍依据，仅地理取象" |
| 港澳台 | 香港、澳门、台北按扬州处理（属中国，古属扬州刺史部范围）；同时说明"现代城市与古代州治无继承关系" |
| 位于两州交界（盐城、信阳、安阳等） | 两州并列，取丙级同向者；若丙级也两可，标"地域五行不明" |

> **不许做的事**：把"议"档城市择一当"定"用。北京写成"属冀州"而不提幽州之说，就是**把两套史料压成一套**，比"不知道"更糟。

## 九、方位五行（甲级，原文直证）

这一节是**方位**这条线上的主判据，能直接引原文。（V1.2 起地域那条线上的州五行也有原文直证了，见 `03a` §1。两条线各自有据，但**依据不同、结论可相反**，见 §9.4。）

> 《五行大义·论八卦八风》："其配五行者，乾兑为金，坎为水，震巽为木，离为火，坤艮为土。各以方位言之。"

| 方位 | 卦 | 五行 | 中心角 | 覆盖角度 |
| --- | --- | --- | --- | --- |
| 北 | 坎 | **水** | 0° | 337.5°–22.5° |
| 东北 | 艮 | **土** | 45° | 22.5°–67.5° |
| 东 | 震 | **木** | 90° | 67.5°–112.5° |
| 东南 | 巽 | **木** | 135° | 112.5°–157.5° |
| 南 | 离 | **火** | 180° | 157.5°–202.5° |
| 西南 | 坤 | **土** | 225° | 202.5°–247.5° |
| 西 | 兑 | **金** | 270° | 247.5°–292.5° |
| 西北 | 乾 | **金** | 315° | 292.5°–337.5° |

### 9.1 二十四山与八方的冲突（必须处理）

二十四山把每个 45° 再切三份，五行与八方**不完全一致**。最典型的是西北乾位：

| 乾位内三山 | 中心角 | 五行 |
| --- | --- | --- |
| 戌 | 300° | 土 |
| 乾 | 315° | 金 |
| 亥 | 330° | 水 |

所以从上海看北京（方位角 336°），八方位判为"西北·乾·金"，二十四山判为"亥·水"。**两者冲突。**

**处理规则**：
1. 主判据永远用**八方位**（有原文直证）
2. 二十四山只作细分参考，写在括号里
3. 两者不同行时，标"**方位杂气**"，该方位的说服力下调一档
4. **不许**因为某个山向更合命局，就改用二十四山来判——那叫凑结论

### 9.2 距离阈值

| 距离 | 处理 |
| --- | --- |
| < 50 km | 视为同城/近邻，方位无意义，按同城处理 |
| 50–300 km | 方位有效，但要注意"同一方位内气候可能剧变" |
| > 300 km | 方位与地域都有效 |

### 9.3 边界提示

方位角落在扇区边界 ±3° 内时，脚本会提示"归属不稳"。这不是瑕疵，是真实情况——换个坐标基准就可能改判。报告里要如实写，不许隐瞒。

### 9.4 方位五行 vs 州五行：四处硬冲突

这是 V1.2 接入《三命通会》卷四后发现的最大问题。两套甲级系统在四个方位上直接对立：

| 方位 | 八卦方位五行 | 该方位的州 → 州五行 | 冲突 |
| --- | --- | --- | --- |
| 东南 | 木（巽） | 徐 → **火** | ❌ |
| 正南 | 火（离） | 荆 → **金** | ❌ |
| 西南 | 土（坤） | 梁 → **金** | ❌ |
| 西北 | 金（乾） | 雍 → **水** | ❌ |
| 正东 | 木 | 青/兖 → 木 | ✅ |
| 正北 | 水 | 冀 → 水 | ✅ |
| 中央 | 土 | 豫 → 土 | ✅ |

> **两点精确化**：① 正南一格里，扬州（火）与离火同向，只有荆州（金）相反，所以是"半冲突"；② 东北艮土，但该方位含冀州（水）一角，也属半冲突。严格说硬冲突是**东南、西南、西北三处**，正南与东北各一半。

**处理规则（不许调和，只许分用）**：

| | 方位五行 | 州五行 |
| --- | --- | --- |
| 回答的问题 | 目的地相对**你现在的位置**在哪个方向 | 这片**地域本身**与哪一行同气 |
| 参照系 | 相对 | 绝对 |
| 依据 | 《五行大义·论八卦八风》 | 《三命通会》卷四得地条 |
| 何时优先 | 用户问"往哪个方向走" | 用户问"这片地方合不合我" |

1. 两栏分列，永不合并
2. 冲突时并列呈现，说明这是两套系统的分歧，不是谁错了
3. 不许为了结论好看而挑一套用
4. 同向可写"两说同向，可信度较高"；相反必须写"两说相反"

详细推导与实例见 `03a-三命通会分野规则.md` §3。

四条必守：
