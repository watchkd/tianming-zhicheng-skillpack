# 清单 · 《五行大义》蒸馏交付

## 一句话

从《五行大义》提炼出 **10 个技能，分两层**。它们都不是断法技能——本书没有任何断法。

- **零件层（5 个）**：给八字分析打底的定义层、关系层、力度层、取象层。
- **外延层（5 个）**：把五行往律历、星象、卦气、宫位、德运、官制、神将、物类八个方向延展，供"深度延展调用"。

## 两批的用法差别

| 面 | 零件层 | 外延层 |
| --- | --- | --- |
| 回答什么 | "这个五行是什么、怎么作用" | "这个五行还能连到什么上" |
| 入口 | 按检查步进入（认体性→查数→判旺衰→判关系→取象） | 按延展方向进入（要位？要时？要德？要将？要物？） |
| 是否能断 | 不能，但贴近断法（旺衰、关系、病位） | 完全不能，多为配属与象数 |
| 风险 | 被误当断法 | 被误当式法（九宫飞星、六壬起课、奇门布局、演禽） |

## 本书结构类型

**概念型**（按"名→体→数→生→配→杂→德→合→扶抑→克→刑→害→冲破→配属→情性→人象"的概念链分章）。

**归并策略**：不作"一概念一技能"的照搬（那会出二十多个碎片技能），而是按**八字分析中的固定检查步**归并为五组。理由：本书概念全落在 L1/L3 底层，不进 L4-L8。若按概念拆，用户拿到一个盘时不知道先开哪个；按检查步拆，则"认体性 → 查数 → 判旺衰 → 判关系 → 取象"是一条可执行的顺序。

### 未产出说明（游年年立）

这一节有实质方法（男丙寅左行、女壬申右转；八卦游年三变祸害/绝命/生气），不是"没内容"。不产出技能的理由是**归属不同**：它是行年/小限体系，与子平大运的排法与用法均不同源。若硬塞进 `xiuwang-shengke`，会让人误以为这是大运算法；若单立技能，则会让人拿它当大运替代品。故只在候选文件里保留，标热度 🔥，等上层断法书到位后，由用户决定要不要与断法书的大运章节合并成一个"运程"技能。

规则以逻辑推导与经典互证为主（郑玄、服虔、京房、翼奉、许慎、《白虎通》、《春秋繁露》、《元命苞》），并以"问曰…答曰…"自设论难。

> 附带说明：原文举过五组干支（庚子、丙寅、壬戌、壬申、己巳），但那是**纳音算法的演算示例**，用于演示"从本命干数到所隶干，数几言得几音"，不含任何人命信息，不能算命例。

## 哪些技能标记为低置信

| 技能 | 置信 | 原因 |
| --- | --- | --- |
| `wuxingdayi-shushu-nayin` | **低** | 两点：①太玄数的"相倍/王十倍/休如本/囚死半"倍数规则，后世命理极少真用，套用会与主流做法冲突（已在失效场景写明）；②本书只给纳音算法，一句断法都没有，用户若拿它断纳音吉凶会落空 |
| `wuxingdayi-quxiang` | **中** | 取象表完整，但每一路都缺"再往下一层"：病候是望诊所见不是病名；五事厥罚的对象是人君不是个人；六情配藏府两说并存需自辨。表中信息可靠，推到最后一步需另加论证 |
| `wuxingdayi-xiuwang-shengke` | **高** | 但有一处高危：极易被当"日主身强弱"用。已在核心判断后与失效场景首条双重设防 |
| `wuxingdayi-xingchong-hehai` | **高** | 但支刑干/干刑支两套与后世体系不同源，须慎用 |
| `wuxingdayi-mingti` | **高** | 内容纯定义，风险最低。唯一风险是被拿去当断法用（已声明） |
| `wuxingdayi-shushu-jiugong` | **高**（表）/ **中**（用） | 表与算法都可复算（洛书五步、纳甲、大衍）。风险在"用"：极易被当九宫飞星或奇门用，已在失效场景首条设防 |
| `wuxingdayi-lulv-qizheng` | **高**（表）/ **低**（占） | 律数、宿度、分野是硬数据。但七政的占法（五星失度、日月蚀）是政论式天象观，无个人断法，拿去断人命必然落空 |
| `wuxingdayi-wude-zhengjiao` | **中** | 表格完整且作者裁定清楚，但整节的语法是"君—民—天下"，移植到个人身上须重写主语。五德形貌尤其易被当相术 |
| `wuxingdayi-shenjiang-shifa` | **中** | 神将配属准确，但没有起课法。有素材无能力，是本包最容易被误用的一处 |
| `wuxingdayi-wulei-quxiang` | **中** | 三十六禽有表有理据，但无断法；且三套异说并存，遇异文要按辨正处理 |
