# 数理与纳音

## 什么时候用它

- 你想知道纳音的**算法本源**，而不只是背六十甲子纳音表。
- 你要判某旬空亡，还想分清是"半空亡"还是"全空亡"。
- 你在用太玄数（甲己九、子午九那一套），想核对，或想知道它随旺衰怎么变。
- 你要查五行的生数与成数，以及"为什么水一六、火二七"。
- 你想知道"土为什么在数上是中心"（因为五），以及"五行皆须土而成"的数理依据。

**不用于**：断纳音吉凶、断运势、断事业。本技能给算法与数表，不给断语。

**前置**：可先过 `wuxingdayi-mingti`（体性）。要判旺衰以定"气之倍数"，接 `wuxingdayi-xiuwang-shengke`。

## 涉及的模型节点

- L3五行 > 五行底层 > 数 > 生成数
- L3五行 > 五行底层 > 数 > 支干数（太玄数）
- L3五行 > 五行底层 > 数 > 纳音数（生数/壮数/老数、五音纳甲、支属八卦）
- L1四柱 > 空亡（半空亡 / 全空亡）
- L1四柱 > 纳音（取数与五音）

## 核心判断

**五行不是靠"五种物质"立起来的，是靠"五组数"立起来的。** 生数一到五，成数六到十，中间那步"得五乃成"才是关键——水得一仍是凝、得五才流。所以土在数上不是第五个成员，是让其余四行"能用"的那个中数。这就是"木非土不生，火非土不荣，金非土不成，水非土不停"的数理根据。

**空亡不是"没有"，是"这一旬里这两支落单了"。** 原文说得很直白："支孤无干，故名为空亡；亡者无也，无干故亡。所对者全虚，故云空也。"所以空亡要分支看：这一支是彻底没干可配（全空亡），还是只剩半个五行在（半空亡）。断"空"之前先分半全，否则一律断"落空"。

## 断法步骤

1. **查生成数** → 取该行的生数与成数。判"这一行是否已经到了能用的地步"：只有生数未成，则未可为用。[L3五行>数>生成数]
2. **核对成数算法** → 生数 + 所寄四季土之五 = 成数（水一+丑五=六、木三+辰五=八、火二+未五=七、金四+戌五=九、土五+五=十）。这一步能验证你没记错。[同上]
3. **查支干数** → 若用太玄数，取支数（子午九…巳亥四）或干数（甲己九…戊癸五）。[L3五行>数>支干数]
4. **按气调数** → 用"相则倍之，王则十而倍之，休则如本，囚死半之"调整。这一步是太玄数真正的用法，多数人只记数不记这个倍数。[同上]
5. **查纳音** → 先取该支所隶之干（子午庚、丑未辛、寅申戊、卯酉己、辰戌丙、巳亥丁），再从本命干数到所隶干，数几言即得几音。[L3五行>数>纳音数]
6. **查空亡** → 定旬 → 找该旬缺的两支 → 判半空亡还是全空亡。[L1四柱>空亡]

## 参考命例

本书命例为零。原文举的庚子、丙寅、壬戌、壬申、己巳五例是**纳音算法的演算示例**，不是命例——它们是"随便取一组干支演示怎么数"，不含任何人命信息。

## 判断标准

- 断对了会看到：你能从支属八卦 + 言数，自己推出任意一柱的纳音，不必查表。
- 断错了会看到：你只记太玄数的数字，不记"相倍、王十倍、休如本、囚死半"这一层；或把空亡一律断成落空，不分半全。

## 什么时候不该用它

1. **不断纳音吉凶**。本书只讲"纳音数怎么来"，没有一句讲"某纳音主什么"。要断纳音吉凶，本书给不了，得另找书。
2. **太玄数不是万能刻度**。它的倍数规则（相倍/王十倍/休如本/囚死半）来自本书，但后世命理很少真按这个算。若你用通行太玄数（如纳音、神煞起例），直接用原始数，别套倍数，否则会和主流做法冲突。
3. **空亡不主吉凶**。本书讲空亡只是旬中干支落单的算法，未给任何吉凶断言。断"空亡主虚、主不成"是后世的说法，不是本书的。
4. **生成数不要当河洛数直接用**。本书的生成数配的是方位与"得五乃成"，与河图洛书、先后天卦数的配法不同源。
5. **大衍数与九宫数不在本技能**。这两段已单独蒸为 `wuxingdayi-shushu-jiugong`（数宫与卦气）。要算蓍策、查洛书九宫、查八卦纳甲，去那个技能；本技能只管生成数、太玄数、纳音数、空亡。
6. **纳音五音≠律吕五音**。本技能的五音是"言数定音"（一言得土曰宫、三言得火曰征）；律吕的五音是"律位定音"（黄钟为宫、林钟为征），在 `wuxingdayi-lulv-qizheng`。两套不要混。

## 出处

来自《五行大义》第三明数（论五行及生成数、论支干数、论纳音数）、第五论配支干。

原文："支干数者。凡有二种。一通数。二别数。……五行及支干之数。相则倍之。王则十而倍之。休则如本。因死半之。以此四而孳。数乃无极。此并从气增减。气盛则多。气衰则少也。"

原文："纳音论其本命。故以终数言之。……一言得土曰宫。三言得火曰征。五言得水曰羽。七言得金曰商。九言得木曰角。此并是阳数。"
