## R-01 五德传授以相克为序

| 项 | 内容 |
| --- | --- |
| 断言 | 五帝传授之序为相克：苍帝"顺金授火"、赤帝"顺水授土"、黄帝"顺木授金"、白帝"顺火授水"、黑帝"顺土授木" |
| 判据 | "此皆五德之依五行，**子母相传**也；非其次者，必有克代而不终也" |
| 用法 | 判某朝／某运之祚长短：得子母相生之次者祚长，得克代者不终 |
| 例证 | 秦以金德代周，二世而亡；汉以火德继周、代秦之伪金，故祚长 |
| 出处 | 08 论五帝 |

> 注意区分：**德之承继**（谁受命）用相生"帝子"说；**德之传授**（如何递接）用相克"顺某授某"说。两说并存于原文，不矛盾。

## R-06 卦气占：四正卦各主一节，得对宫之气则成

| 项 | 内容 |
| --- | --- |
| 震主春分谷雨 | 谷雨得天兑（日在昴，西方之宿）则万物毕生；貌顺木得则天兑为和；貌失木逆则天兑为害，常雨为罚 |
| 兑主秋分霜降 | 霜降得天震之动气则天下霜、万物死；言顺金得则和；言失金逆则害，旱罚 |
