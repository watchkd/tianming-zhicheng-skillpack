# 辨正（续篇）· 《五行大义》

> 只收"两说相反 → 作者表态 → 表态理由"的条目。作者未表态者标【两存】，并说明为何不能强裁。

---

## D-01 五帝到底是谁 —— 作者裁：伏羲至颛顼

| 项 | 内容 |
| --- | --- |
| 三说 | ①《河图》：青帝灵威仰、赤帝赤熛怒、黄帝含枢纽、白帝白招拒、黑帝叶光纪（**五天帝**）②《礼记·月令》：大皞、炎帝、黄帝、少昊、颛顼（**五方人帝**）③诸史：少昊、颛顼、高辛、唐、虞（**史书五帝**） |
| 作者裁 | "今案礼记郊配五德，**自伏羲至颛顼为五帝，是其正位**" |
| 理由 | ①《易》称"帝出于震"，震为木、为东方、主春，五德之首在木 ②"以次而行，至颛顼则五德数终" ③若以少昊为首，"则金非五德之先" ④若以黄帝为首，"土居中央，本非创始" |
| 用法 | 论五德终始、德运形貌，取"伏羲—炎帝—黄帝—少昊—颛顼"这一次序；论五星帝子、太微五帝，取河图五天帝名 |
| 出处 | 08 |

## D-02 太一是不是"北辰神名" —— 作者裁：郑玄错

| 项 | 内容 |
| --- | --- |
| 郑说 | 郑玄注《乾凿度》："太一者，北辰神名。居其所曰太帝，行八卦日辰之间曰太一，或曰天一" |
| 作者裁 | "此并紫微宫门外天一、太一，**非紫微之内北辰之名大帝也。郑玄谬矣**" |
| 理由 | 紫微宫门外有两星俱侍，"天皇太帝、天一"；北辰（曜魄宝）在勾陈中，是"五帝之尊祖"，与门外侍星非一物 |
| 影响 | 后世常把太一＝北极星，本书不同意。用本书时须分清"紫微内之北辰"与"紫微门外之天一太一" |
| 出处 | 07 |

## D-03 斗星分野两套 —— 【两存】

| 系统 | 配法 |
| --- | --- |
| 合诚图系 | 枢星雍州、璇星冀州、玑星青兖州、权星徐扬州、衡星荆州、开阳星梁州、标光星豫州（**七星配七州，无青徐扬之分**） |
| 九宫系 | 枢＝炎天＝离＝扬州、璇＝变天＝艮＝兖州、玑＝昊天＝兑＝梁州、权＝幽天＝乾＝雍州、衡＝钧天＝中＝豫州、开阳＝阳天＝巽＝徐州、瑶光＝苍天＝震＝青州 |

**不裁之由**：两套一为"斗星主州"，一为"九天—九宫—九州"三层对应；后者有九位而斗只有七星，故其一星可主两州。原文两处并存，未作取舍，且都自称"三才之道，并为斗之所政"。用时**按所据系统取一套，不可交叉混配**。

## D-04 九州在九宫的位置 —— 作者裁：微移无碍

| 项 | 内容 |
| --- | --- |
| 九宫经位 | 冀州坎（正北）、荆州坤（西南）、青州震（正东）、徐州巽（东南）、豫州中、雍州乾（西北）、梁州兑（正西）、兖州艮（东北）、扬州离（正南） |
| 太一家位 | 兖州坎（正北）、青州艮（东北）、徐州震（正东）、扬州巽（东南）、荆州离（正南）、梁州坤（西南）、雍州兑（正西）、冀州乾（西北） |
| 作者裁 | "此并从五行本始之气……**虽宫位微移，五行气一**" |
| 理由 | 太一家以"五行本始之气"定位（西北亥地坎水居之、东北寅地震木居之、西南巳地离火居之、西南申地兑金居之），九宫经以州之实际方位定位 |
| 用法 | 论州之方位取九宫经；论州之气本取太一家。二者不混 |

## D-05 麟属木还是属金 —— 作者裁：龙木、麟土、虎金

| 项 | 内容 |
| --- | --- |
| 诸说 | 衍孔图"麟为木精"；大戴礼"麟为毛虫"（毛虫属西、属金）；公羊高"麟为木精"；保乾图"岁星为麟"；考异邮"麟者阴精"；蔡邕"麒麟之信"（信主土） |
| 作者裁 | "**木之义扶龙**……**是土之义扶麟**……**故金义扶虎**" |
| 理由 | ①木者触也，有触冒之义：麟有肉角无所抵触，龙角端无肉有抵触义；易象震为龙，故木归龙 ②天官有"大角轩辕麒麟之信"，信主土，修母子应 ③虎为毛虫、七月生应阳数、参代虎之德主义主斩刈，故金归虎 |
| 连带 | 若麟属金，则虎无用——这是作者驳回"麟金"说的关键 |
| 出处 | 10 |

## D-06 三十六禽异说 —— 作者裁：从"孟暮仲昼季旦"

| 项 | 内容 |
| --- | --- |
| 分歧 | 王简说、本生经说、禽变说三套，同一支的三禽名互有出入（如卯：貉／鹤；巳：蛇／龟／蝉；酉：乌／死石／死土／鸢） |
| 作者裁 | "虽本生经及禽变互有不同，**昼暮之位，理从前解**" |
| 前解 | "以气而取：孟则在暮，仲则在中，季则在旦"——孟为一时之首气未盛（近暮），仲气盛在中（昼），季为一时之末气已衰（近旦） |
| 用法 | 取禽名从通行一套（配属 9.4 所列），取"朝／昼／暮"之位从孟仲季气盛衰之理解释，不必逐条从异说 |
| 出处 | 10 |

## D-07 离卦为何不配马 —— 作者裁：坤马在未、未午合

| 项 | 内容 |
| --- | --- |
| 问 | 八卦配禽，离不言马；禽变乃以午为马，何？ |
| 答 | "坤为牝马之贞，坤既在未，未与午合，故马居午" |
| 再问 | 乾亦称马、震亦称马，何不并取其合？ |
| 再答 | "行地莫过于马，坤既是地，取其正用；乾天震木，非是地体，故不取合" |
| 出处 | 10 |

## D-08 乾六爻皆龙，龙为何居辰 —— 作者裁：戌冲辰

| 项 | 内容 |
| --- | --- |

## D-09 律、吕之名 —— 【两存】

| 名 | 诸解 |
| --- | --- |
| 律 | 率也（元命苞）／术也（续汉书）／法也（三礼义宗）／帅也（"帅导阳气使之通达"） |
| 吕 | 序也（律书，"序述四时之气，定十二月之位"）／助也（"助阳成功"）／侣也（"与阳为侣"）／距也（"阴阳之气有时相距"） |

**不裁之由**：四解各就一面立义，非互相排斥。律兼"率／法／帅"三义为一事（皆言主导），吕兼"序／助／侣／距"为一事（皆言辅从而有阻）。用时按语境取，不必择一。

## D-10 律数与律长两套 —— 【两存】

| 套 | 数 |
| --- | --- |
| 律数（黄钟之数） | 黄钟81、林钟54、大蔟72、南吕48、姑洗64、应钟42、蕤宾56、大吕76、夷则51、夹钟68、无射45、中吕60 |
| 律长（三元律） | 黄钟九寸（天元）、林钟六寸（地元）、大蔟八寸（人元） |

**不裁之由**：律数是"管长九寸→九九八十一"的积数，用于三分损益递推；律长是三元之象征数（九＝阳极、六＝阴中、八＝象卦），用于配三统。两者不在同一坐标系，不冲突。

## D-11 二十八宿五行：总配与别配 —— 【两存，一体两用】

| 套 | 配法 | 用途 |
| --- | --- | --- |
| 总配 | 以方定一行：东七宿木、南七宿火、西七宿金、北七宿水；角亢、井鬼、奎娄、斗牛"居四季为土" | 论方与季、论大体所属 |
| 别配 | 以宿定：或单属一行（角木、房土、尾水、张水、斗木、牛木），或分春夏／秋冬两行（亢春夏火秋冬水等） | 论一宿之细属、论时变 |

**不裁之由**：原文并列两套，且明确"星二十八宿配五行有二别，一总配，二别配"。总配是空间属性，别配是时间属性（同一宿在不同季节换行）。用时先问"你要的是方位还是时令"。

## D-12 五德：承继用相生、传授用相克 —— 【并存不矛盾】

| 面 | 说 |
| --- | --- |
| 谁受命（承继） | "木王则苍帝之子，火王则赤帝之子……"——以**相生**定帝子 |
| 如何递接（传授） | 苍帝"顺金授火"、赤帝"顺水授土"、黄帝"顺木授金"、白帝"顺火授水"、黑帝"顺土授木"——以**相克**定传授 |
| 判祚 | "非其次者，必有克代而不终"——克代者祚短（秦金代周，二世而亡）；子母相承者祚长（汉火继周） |

**提示**：这不是矛盾，是两个不同问题。混用会得出"汉当为土德"之类的错结论。

## D-13 五音配律 vs 纳音五音 —— 两套，切勿混

| 套 | 内容 | 出处 |
| --- | --- | --- |
| 律吕五音 | 黄钟为宫、林钟为征、大蔟为商、南吕为羽、姑洗为角、应钟为变宫、蕤宾为变征 | 03 引乐纬 |
| 纳音五音 | 一言得土曰宫、三言得火曰征、五言得水曰羽、七言得金曰商、九言得木曰角（以"言数"定，非以律位定） | 第三论纳音数 |

**警示**：纳音虽是"纳律吕之音入干支"，但其取音法不是查律位，而是数"本命干到所隶干"的言数。二者名同实异，混用必错。

## D-14 天一／太一行宫起点 —— 【两存】

| 说 | 内容 |
| --- | --- |
| 九宫经 | "天一之行始于离宫，太一之行始于坎宫" |
| 郑司农／郑玄 | "太一行八卦之宫，每四乃入中央"；"太一下行九宫，从坎始" |

两说在"太一从坎始"上一致，分歧只在"天一从离始"是否另有其行。原文并列，且分主"天一主丰穰、太一主水旱兵饥"，本为两神两行，不构成冲突。

## D-15 十二属为何不取麟凤 —— 作者答：无所作动

| 项 | 内容 |
| --- | --- |
| 问 | 禽虫之例数多，何故不取麟凤为属，乃取蚯蚓蛇鼠小虫？ |
| 答 | "取十二属者，皆以其**知时候气**，或色或形，并应阴阳故也。麟凤已配五灵，非是虚而不用" |
| 再问 | 麟凤已配五灵更不取，龙虎亦配五灵，何为复用？ |
| 再答 | "龙动云兴，虎啸风起，此是应阴阳之气，所以须取；麟凤虽灵，无所作动，故不重用" |
| 要点 | 入十二属的资格不是"贵"，是"能候气、有动象" |

## D-16 两种"形貌"不可混

| 套 | 内容 | 出处 |
| --- | --- | --- |
| 五帝之体 | 苍帝"体为苍龙"、赤帝"体为朱鸟"、黄帝"体为轩辕"、白帝"体为白虎"、黑帝"体为玄武"——是**帝之象**，非人形 | 08 引录图 |
| 承德之君 | "为人青色、修颈美发，其民长身广肩，尚仁"——是**受命之君与其民**的人形与民性 | 06 引录图 |

**警示**：两处都称"录图"，都讲形貌，但一指天帝之象、一指人间之君。用来推人命形貌时，只能取后者。
