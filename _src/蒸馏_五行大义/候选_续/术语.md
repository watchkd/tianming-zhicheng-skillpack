# 术语（续篇）· 《五行大义》

> 覆盖：续 02、03、04、05、07、08、09、10。只收"名之训"——某个名为什么叫这个，不作吉凶判断。

---

## 一、总名

| 名 | 训 | 出处 |
| --- | --- | --- |
| 九宫 | "皆神所游处，故以名宫也"；上分于天（二十八宿、北斗九星），下别于地（四方四维及中央） | 02 |
| 律 | 率也／术也／法也／帅也——"帅导阳气，使之通达" | 03 |
| 吕 | 序也（序述四时之气、定十二月之位）／助也（助阳成功）／侣也（与阳为侣）／距也（阴阳之气有时相距） | 03 |
| 七政 | "乃是玄象之端，正天之度，王者仰之以为治政，故谓之政"；七者数有七 | 04 |

| 五帝（天帝） | 天上神，下治于世，综理神鬼，治太微宫，"其精为五帝之座，五星随王受气" | 08 |
| 五灵 | "五禽于虫兽之中最灵，故曰五灵" | 10 |
| 五虫 | 羽／毛／甲／鳞／倮各三百六十，皆称虫 | 10 |

## 二、十二律名训

| 律 | 训（三礼义宗为主，附淮南子／白虎通） | 月气之象 |
| --- | --- | --- |
| 黄钟 | 黄，中和之气（淮南：土色）；钟，动也／应也——阳气潜动于黄泉之下，应养万物，萌牙欲出 | 十一月，冬至得之，"黄钟为君" |
| 大吕 | 大者太也；吕者距也——"阳气欲出，阴距难也"（淮南：吕者旅也，旅而去也） | 十二月，阳方生长，阴气助之 |
| 大蔟 | 蔟者凑之义——"万物始大，凑地而出"（淮南：万物蔟而未出） | 正月 |
| 夹钟 | 夹者佐也——"阴佐阳气，应时而出"；一云夹者侠也，为孚甲所侠，至此方解 | 二月 |
| 姑洗 | 姑者古（枯）也，洗者鲜也——"万物去故就新，莫不鲜明"；洗除其枯 | 三月 |
| 中吕 | 中，宛也；吕者距难之义——"阴欲出，阳气在于中距执之" | 四月，阳气盛长，阴助功微 |
| 蕤宾 | 蕤，垂下之义；宾，敬也——"五月阳气下降，阴气始起，共相宾敬"（淮南：安而服也） | 五月 |
| 林钟 | 林，众也／茂盛也——"万物成熟，种类众多"，"聚积于野"（淮南：引而止之） | 六月 |
| 夷则 | 夷，伤也／平也；则，法也——"万物始伤，被刑法"；一云"平均结实，皆有法则"（淮南：易其则也） | 七月 |
| 南吕 | 南，任也——"阳气有任生孳长"；"物皆含秀，有怀任之象，助成功之义"（淮南：任苞大也） | 八月 |
| 无射 | 射，终也／厌也——"万物随阳而终，当复随阴而起，无终已也"；"物皆成实，无可厌恶" | 九月 |
| 应钟 | 应其所钟——"岁功皆成，阴气之用，应阳之功，收而聚积"；又应和之义，"将复应阳气而动于下" | 十月 |

| 房 | 天子四时所居，故名房 |

| 女 | 方正，裁割之象，婢妾之类 |
| 虚 | 耗也，其间空虚，庙堂之象 |
| 危 | 似室屋，亦如坟墓 |

| 胃 | 在藏为五谷之府，主廪仓 |

| 参 | 共也，杂金土之气，共行杀罚 |

| 鬼 | 归也，阳归于阴；其内一星闇而不明，鬼之象 |
| 柳 | 留也；一名任，祭祀鬼神、合和五味、留神灵 |
| 星 | 数七，如鸟之衣覆上 |
| 张 | 开张也，为朱鸟之嗉，有容纳，故主宾客 |
| 翼 | 如六翮，似鸟两翅之飞 |
| 轸 | 似小车四马，车后横曰轸，凶事之用 |

## 四、八风名训

| 风 | 训 |
| --- | --- |
| 广莫 | 广，大也；莫，沙漠也——寒气广远，自沙漠而来；一云阳气在下，阴莫之广大 |
| 条 | 条，达也——达生万物 |
| 明庶 | 庶，众也——阳施惠之德，众物皆明出 |
| 清明 | 天气明净清凉，清风吹万物使盛大明净可观 |
| 景 | 景，高也／竟也——万物至此太高；阳道至此终竟 |
| 凉 | 秋风凉，阴气凄凉，收成万物 |
| 阊阖 | 昌盛也——万物盛而收藏；阊，大也，阖，闭也，收闭之时 |
| 不周 | 周，遍也——万物备成；不周者闭不通，纯阴无阳，闭塞不通 |

**八门**：苍门（东北，木将用事）、开明门（东，日之所出）、阳门（东南，纯阳用事）、暑门（南，盛衰之时）、白门（西南，金气之始）、阊阖门（西，万物将收）、幽都门（西北，玄冥将始用事，阴聚故幽）、寒门（北，积寒所在）。

## 九、易混词辨

| 词 | 本书中的意思 | 不是 |
| --- | --- | --- |
| 七政 | 日月五星／北斗七星／二十八宿（三说并存） | 不是七种政事 |
| 九宫 | 洛书九位＋九神游处 | 不是九宫飞星之"宫"（后世借用） |
| 三正 | 天正建子、地正建丑、人正建寅（三代岁首） | 不是三统历之"三统"（名近而所指有别） |
| 三统 | 天统／地统／人统，与三正同实而异名 | — |
| 五帝 | 天帝（灵威仰等）／五方人帝（庖羲等）／史书五帝（少昊至虞舜）三系 | 不是"五个皇帝"单一所指 |
| 五祀 | 句芒、祝融、后土、蓐收、玄冥五神 | 不是《礼记》门行户灶中之五祀 |
| 十二将 | 天一前后各五共十二（腾蛇至天空） | 不是六壬十二神将（神后至微明） |
