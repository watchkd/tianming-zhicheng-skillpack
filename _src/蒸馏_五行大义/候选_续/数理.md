# 数理（续篇）· 《五行大义》

> 覆盖：续 01 起大衍、02 论九宫数、03 论律吕、04 论七政、09 论诸官、10 论禽虫。

## 一、大衍之数

| 配置 | 断言 | 出处 |
| --- | --- | --- |
| 总数 | "凡大衍极天地之数，五十有五也"＝天一至地十 | 01 |
| 用数 | 五十有五之中，用四十九（虚一） | 01 |
| 京房解 | 十日＋十二辰＋二十八宿＝五十；其一不用者为"天之生气"，"将欲以虚求实，故用四十九" | 01 |
| 马融解 | 太极为北辰，居位不动；两仪→日月→四时→五行→十二月→二十四气，其余四十九转运而用 | 01 |
| 郑玄解 | 贞悔六爻本有五十，定所用者四十九；天地之数本五十五，"并则宜减"，大衍减五为五十，其用减一为四十九 | 01 |
| 虚一之义 | "挂一象无，无无可象，故有之用极，则无之功见" | 01 |
| 揲法 | 分二以象两，挂一以象三，揲之以四以象四时 | 01 |
| 余数命爻 | 余四七故名七，余四八故名八（静爻之数）；余四九故名九，余四六故名六（动爻之数） | 01 |
| 静动分用 | 夏殷尚质，用静爻占；周备质文，兼用动爻 | 01 |
| 静动之理 | 七为少阳，九为老阳，"阳动而进，变七之九，象气息也"；八为少阴，六为老阴，"阴动而退，变八之六，象气消也" | 01 |
| 还原链 | 寻大业得吉凶 → 吉凶得八卦 → 八卦得四时 → 四时 → 两仪 → 太极 | 01 |
| 数之定位 | "数之显理，犹筌蹄之取鱼兔"；"太极无所复象，明其空寂，非言象所诠" | 01 |

> 要点：七九八六不是四个数，是"气之进退"的四个阶段。七→九为进（阳长），八→六为退（阴消）。这一点是后世"老阳老阴变爻"的源头。

## 二、律数

| 配置 | 断言 |
| --- | --- |
| 黄钟本数 | 管长九寸；九为阳数之极，三三如九；九九八十一为黄钟之数 |
| 起数之理 | "数之所起，起自于三"，三才之道合成数；阳得兼三故称九，阴但兼二故称六 |
| 十二律数 | 黄钟81、大吕76、大蔟72、夹钟68、姑洗64、中吕60、蕤宾56、林钟54、夷则51、南吕48、无射45、应钟42 |
| 上下生 | 阳生阴曰下生（三分减一：二乘三除）；阴生阳曰上生（三分益一：四乘三除） |
| 三元律长 | 黄钟九寸（天元）、林钟六寸（地元）、大蔟八寸（人元）；"八象于卦" |
| 律历同构 | "律历者，天所以运五行八正之气，成熟万物也" |

> 律数与十二辰、十二月建、十二次严格同构，这是本书"律历一体"的骨架：一律对应一辰、一月、一次。

## 三、九宫算法

### 3.1 三层减数

| 步 | 减 | 余 | 义 |
| --- | --- | --- | --- |
| 起 | — | 55 | 天地之数 |
| 一 | 天1、地2、人3 | 49 | 蓍策之数 |
| 二 | 四时4 | 45 | 五行5 ＋ 五行成数40 ＝ 一节之数 |
| 三 | 分五方 | 方各9 | 一时九十日 |
| 四 | 三宫相对 | 15 | 一气之数，成二十四气 |

### 3.2 配算成洛书（"木落归本"五步）

| 步 | 口诀 | 操作 |
| --- | --- | --- |
| 1 | 木落归本，分六至亥 | 取震六算置于乾 |
| 2 | 水流向末，分八至丑 | 取坎八算置于艮 |
| 3 | 金义而坚，分二还未 | 取兑二算置于坤 |
| 4 | 火本炎盛，自处其乡 | 离算不动 |
| 5 | 土王四季，本生于巳 | 分中宫四算置于巽 |

> 由此成"戴九履一"之位。此段是**洛书数的构造过程**，不是口诀，可复算。

### 3.3 初成八卦法（干支布位）

| 步 | 操作 |
| --- | --- |
| 1 | 取北方九算，命"水生木"：纵一置寅、一置卯、一置辰；横一置甲、一置乙 |
| 2 | 取东方九算，命"木生火"，于南方布五位 |
| 3 | 取南方之算，命"火生土"：中央一算，西北为戊，西南为巳（己） |
| 4 | 取中央之算，命"土生金"，于西方布五位 |
| 5 | 取西方之算，命"金生水"，于北方布五位 |
| 6 | 加阴干各一（阴数偶）；加阳支各一（支体本） |
| 7 | 余算：一置西北为乾之始，二置西南为坤之始，九置中央为易象 |
| 8 | 纳甲成卦：乾主甲壬、坤主乙癸、震主庚子午、巽主辛丑未、坎主戊寅申、离主己卯酉、艮主丙辰戌、兑主丁巳亥 |

### 3.4 生成之链

易 → 太一 → 天 → 水 → 木 → 火 → 土 → 金 → 八卦 → 十二月 → 万物归地

> 原文以"变字"为说（变易字为太一、变太一为天、变天为水……），属字源式推演，取其序不取其字。
