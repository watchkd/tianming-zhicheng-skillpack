# 候选 · 辨正（作者驳正的两说与异解）

> 轨道：辨正（对应通用版的"误区"轨道）。本书无"常见错误断法"，但有大量"两说相反—作者裁决—裁决理由"的结构，是本书方法论最值钱的部分。

## B-01 六气配五行：服虔 vs 郑玄 ｜块06

| 说 | 配法 |
| --- | --- |
| 服虔注左传 | 阴→土、阳与风→木、雨→金、晦→水、明→火（唯天阳不变） |
| 郑玄注礼记 | 木→雨、金→阳、火→燠、土→风、水→寒 |

**作者裁决：取服虔。** 理由："水生于金，金体非阳；木为少阳，不应为雨；土为地，地本是阴；风自是阴阳之气，不独生于土。服以木为风者，取巽木，故为当也。"

**转用提示**：若取郑说，则"木为雨"会推出"木主湿"，与木主条达发散相悖。取服说则木得风（动、散）之义，与木性同。

## B-02 六情配藏府：论衡 vs 翼奉 ｜块06

| 说 | 配法 |
| --- | --- |
| 论衡（四时论藏） | 肝喜、肺怒、肾哀、脾乐，心为主 |
| 翼奉（风通六情论府） | 好→膀胱、怒→胆、恶→小肠、喜→大肠、乐→胃、哀→三焦 |

**作者处理：两说并存，"二理并通"，不裁优劣。** 差异处：脾肾二种藏府相同；肝肺二藏及府不同——"藏以肺有杀罚之性故怒，府以合肺金珍之用故喜；肝则以春气生故喜，胆则以合火能焚燎故怒"。

**转用提示**：断"某情偏盛"时，藏与府是两条并行线索，可互参不可混为一谈。

## B-03 五常配五行：郑玄诗纬 vs 毛公京房汉志 ｜块05

| 说 | 配法 |
| --- | --- |
| 郑玄注中庸／诗纬 | 木仁、金义、火礼、**水信**、**土智** |
| 毛公传说／京房／汉书天文志 | 木仁、金义、火礼、**土信**、**水智** |

**作者裁决：取毛公京房汉志（土信水智）。** 理由："郑玄及诗纬以土为智者，以能了万事莫过于智、能生万物莫过于土，故以为智；水为信者，水之有潮依期而至，故以水为信。此理寘证狭，于义乖也。"

作者自建论证：仁以恻隐为体博施为用 ↔ 木覆冒滋繁；礼以分别为体践法为用 ↔ 火灭暗昭明；智以了智为体明睿为用 ↔ 水含润流通；义以合义为体裁断为用 ↔ 金坚刚利刃；信以不欺为体附实为用 ↔ 土持载含容以时生万物。

> 这与后世八字"木仁火礼土信金义水智"完全一致 —— 即本书这一裁决，成了后世的通行配法。这是本书对八字体系最直接的一处遗留。

## B-04 五藏配五行：古文尚书 vs 今文 ｜块05

| 说 | 配法 |
| --- | --- |
| 今文（夏侯欧阳）／素问／周礼疾医 | 肝木、心火、脾土、肺金、肾水 |
| 古文尚书 | 脾木、肺火、心土、肝金、肾水 |

**作者裁决：今文为是（即通行配法）。** 理由：引郑玄驳月令五祭之文，辨"凡言先，有后之辞"，认为月令祭序是"以四时之位、五藏之上下次之"，"此义不与行气同也"；并以"周礼疾医以肝为木……则疾多瘳，反其术则死"为验。

**转用提示**：古文说（脾木肺火心土）在命理断病中绝不可用，用则全盘错位。

## B-05 土之生死葬处：诸说互异 ｜块02

| 说 | 土之生死 |
| --- | --- |
| 五行书（通行） | 土受气亥、胎子、养丑、寄行寅、生卯、沐浴辰、冠带巳、临官午、王未、衰病申、死酉、葬**辰** |
| 五行书（四土分王说） | 辰土王辰、未土王未、戌土王戌、丑土王丑，各有全套生死 |
| 高堂隆 | 土生于未、盛于戌、壮于丑、终于辰，"长为水土墓，故辰日不哭" |

**作者裁决**：土葬于辰为正（"进水休就辰，辰是水墓，水为其妻，于义为合"），斥高堂隆说"盖为浮浅"；四土分王说则"此盖卜筮所用"，与"定位王相"不同层，两存。
并明确定位："若论定位王相及生死之处，皆以季夏六月为土王之时……土德于未，终于丑……土王定在于未，墓定在辰也"。

## B-06 水火能否相杂 ｜块03

| 说 | 内容 |
| --- | --- |
| 通说（体不相容） | 金中无木、木中无金（正相害）；水中无火、火中无水（正相害） |
| 作者补充（弱能入坚） | "石中亦有火"、"炎州有树生于火中"、"海中阴火潜燃"——但"非水体杂火"、"体不相杂"，只算"稍涉灵奇，亦非五行常准" |

**作者结论**：体之相容与否由**质地坚弱**决定——"质弱者则体相容，质坚者则体不相容"；"弱能入坚，坚不能入弱"。故火性弱能入石，水中不能容金木。

## B-07 火为何不能烧石 ｜块03

| 现象 | 作者解 |
| --- | --- |
| 木中有火，火还烧木 | 生火方盛，故能烧木 |
| 石中有火，火不烧石 | 火至金乡气已衰，故不能烧石 |
| 火能消金 | 取其盛，故能烁金，"是不取衰火" |
| 金能克木而铅锡不能断 | "此是不坚之金也" |

> 这一组是本书"力量随盛衰而变"的最好例证，可直接支撑"同一组生克，在不同旺衰下结论相反"这条断法原则。

## B-08 扶抑之问难 ｜块03

**问**：母训子教以义方，欲其成人，何为反恶（反为凶）？
**答**：分两种——遇一德合则虽抑非害；有气为真父母，是欲其成人，但"当训之时，于子交不遂心，亦是留碍"；若逢刑克则凶更重。无气为鬼神者，"鬼神之来多欲为祟，祷请祈求及可致福"。
**再问**：既云无气为鬼神，何所虑而能为抑？
**答**："就抑则有，语形则无"；"就气而论，非是全无，但无王相之气而有死没之气。王相气来则吉，死没气来则凶。所言无气者，无王相气耳。"

> 这是全书对"什么叫无气"最精确的一处界定：**无气 ≠ 无，而是无王相之气**。八字里判"某五行无气"，应取此义，不能理解为"该五行不存在"。

## B-09 冲破与沴之别 ｜块04

**问**：沴气是相冲而为，今解冲破而不唤为沴，何也？
**答**："五行相沴，因事变重，非是常然，有罚则见，无灾则止。今之所解，直是支干之位，常自格对，刚柔相冲，非问变异。"

> 界定：**冲破是常态的位对关系，沴是异常灾变**。断命只谈冲破，不谈沴。这条划清了"结构关系"与"灾异应验"的界线。

## B-10 游年为何男从离起 ｜块07

**问**：天一之行以坎为一宫、离为九宫；八卦游年乃以离为一宫，何也？
**答**："天一于天下九州之事，故从始一而行；游年于八年命之事，故以终九而起命。男以德苞终始，故九一并数，起太阳之位；女以阴生阳，故从其创始阴位而行。"

> 说明游年与九宫是两套不同的起点逻辑，不可互套。
