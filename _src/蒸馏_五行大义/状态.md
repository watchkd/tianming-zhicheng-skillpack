## 执行方式偏离

书名下仅 7 块、4.6 万字。原设"每批五路子 Agent 并行"未启用，改为**单线通读提取**：7 块全部由主 Agent 逐块通读后统一归并。理由：块的体量（1.1k–8k 字）小于派发与回收的开销，且本书概念高度互文（同一"德"散在论德/论合/论扶抑三处），单线提取更不易拆散。**逐块回执仍保留在各候选文件开头**，七块全覆盖，无遗漏。
