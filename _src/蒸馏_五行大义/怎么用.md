# 怎么用

## 一、导入

1. 打开 AI 助手，找到「技能」或「插件」入口。
2. 点「导入」，选中 `技能包/` 目录下**某一个技能文件夹**（是整个文件夹，不是里面的 SKILL.md）。
3. 十个技能分开导入，一个一个来。按需开，不必全开。

> **为什么不必全开**：十个技能同前缀，全开会让匹配变糊。但它们的 description 已经各自锁死了方向（名／数／生克／关系／取象／宫／律／德／将／物），只要你不问跨方向的问题，不会抢。真拿不准时全开也无妨——测试里十技能交叉 26 题全过。

### 三题最容易走错的

| 问法 | 正解 | 为什么容易错 |
| --- | --- | --- |
| "纳音的五音和十二律的五音是一回事吗" | 必须双给 `shushu-nayin` + `lulv-qizheng` | 同名异实：一个是言数定音，一个是律位定音 |
| "我这八字火旺会得什么病" | `quxiang`（个人五藏），不是 `wude-zhengjiao` | 政教技能里的病是"民病"，主语是国家 |
| "寅位为什么配虎" | `wulei-quxiang` | 会用到艮为山、箕主风，但问的是配禽之理 |

## 四、必须知道的四件事

### 1. 这十个技能不断命

它们给的是**定义、关系、力度、取象、配属**。它们能告诉你"寅申是直冲不破，所以轻"，但不会告诉你"所以这个人会离婚"。要出断语，得另配一本断法书的技能包，或者你自己把零件组装成结论。

**别说"用它断不准"——它本来就不负责断。** 本书成书早于子平术，全书没有日主、十神、格局、大运、命例。

### 2. 有素材 ≠ 有能力

外延层最容易犯的错，是把"书里有九宫"当成"能飞星"，把"书里有遁甲九神"当成"能布奇门局"，把"书里有三十六禽"当成"能演禽起课"。

| 书里有什么 | 书里没有什么 |
| --- | --- |
| 洛书九宫、八卦纳甲 | 九宫飞布的流年规则 |
| 六壬十二神将配支 | 四课三传的起课法 |
| 遁甲九神配宫 | 局式、门迫、格局 |
| 三十六禽配十二支 | 禽星配日、演禽断诀 |
| 二十八宿度数分野 | 推步历算 |

### 3. 三个高危误区（已在技能里设防，你也要注意）

| 误区 | 后果 |
| --- | --- |
| 拿四时休王表给**日主**定身强弱 | 会得出"春天生人一律身强" |
| 把本书的"扶抑"当"扶抑用神" | 母得子为扶、子遇母为抑，讲的是两行母子向背，不是身弱喜扶 |
| 把"财""官""鬼"读成十神 | 全书零处十神，这些字只是相克胜负与阴阳刚柔的身份比喻 |

外延层另有三个：

| 误区 | 后果 |
| --- | --- |
| 把五德之君的形貌当相术 | 主语是"受命之君与其民"，不是某个人 |
| 把守恒的政令灾异当个人健康断语 | "民病足疾"是说国政失木，不是说你肝不好 |
| 把斗星分野与九宫分野混配 | 两套并存，交叉混配必错 |

### 4. 作者裁决过的几处，用裁决的那一套

| 争点 | 用哪套 |
| --- | --- |
| 五常配五行 | 土为信、水为智（毛公京房汉志）。郑玄诗纬"土智水信"被驳回 |
| 五帝是谁 | 伏羲至颛顼为正位（非少昊至虞舜） |
| 麟属何行 | 土（龙木、麟土、虎金） |
| 三十六禽取哪套 | 禽名取通行本，位次按孟暮仲昼季旦 |

## 五、下一步：配一本断法书

本书是底层与外延，缺上层断法。要真正能断命，建议再蒸一本断法书，两包分层用：

- 分析时**先查底层**（体性、旺衰、关系），再走**断法路径**（取格 → 用神 → 断事）。
- 推荐按你的需求选：
  - **《子平真诠》**——格局型，最适合系统学断法，讲成格破格与用神相神。
  - **《穷通宝鉴》**——调候型，按月令×日干矩阵给喜忌，查表即用。
  - **《滴天髓》**——概念型，讲体用衰旺通关，偏原理。
  - **《渊海子平》《三命通会》**——体量大、混合型，格局神煞纳音命例都有。

把那本书的全文发给我，说一句"蒸这本"就行。两层到位后，`游年年立`（现在只存在候选里，没出技能）也可以并进断法书的运程章节一起处理。
