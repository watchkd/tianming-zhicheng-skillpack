# 《五行大义》骨架

> 隋·萧吉撰，二十四篇。本条为「底层零件库」路线 —— 不作八字断法技能，只提炼可挂到四柱模型 L1/L3 底层的定义、关系与取象零件。

## 一句话主旨

五行不是五种物质，而是五套**气数体性**：每一行有固定的体（形质）、性（功用）、数（生数成数）、位（时方）、配（色声味藏常事）。八字之所以能断，前提是这五套参数先在盘上各就各位；参数错位，后面一切断语都是空中楼阁。

## 作者的核心命理主张

1. **"生数为本，成数为杂"**——一行不是纯一，木中有火、有水、有金、有土。这是本书最独特的一条：五行在盘上从来不是纯气，论力量必须先拆"本气"与"杂气"。
2. **"阴阳之数，始乎一周；五行皆得中气而后成"**——土不是第五行，是四行得"五"才成用的那个中数。故"木非土不生、火非土不荣、金非土不成、水非土不停"，土在盘中是成事条件而非竞争者。
3. **"当王之子为相，父母为休，所畏为死，所克为囚"**——旺相休囚死不是五个并列状态，而是由一条母子-畏-克的关系链推出来的。这套定义比后世口诀更根本。
4. **"冲气为轻，破气为重"，且孟仲季各有生死**——四孟有生无死故"直冲而不破"，四季有死无生故"直破而无冲"，四仲死生俱有故"并有冲破"。冲与破不是同义词，力度可算。
5. **"德不孤立，对之以刑"**——德与刑是一对，不是吉神凶煞的清单。遇德则吉、逢刑则凶，但德刑各随月建出入室堂庭门巷街，同一个"德"在不同月令效力不同。
6. **"情胜性则乱，性胜情则治"**——性情不是并列描述，性为本、情为末，六情触境而变。断性情要先看本（五性）再看末（六情），不能见一情就下断语。
7. **"五行所恶，其在破冲"**——六害不是独立神煞，是"与破冲合"三方交争的产物。害的吉凶不固定：丑午相害是纯凶，未子相害是凶中有吉。这一条直接否定了把"六害"当固定凶兆的用法。

## 结构主干（决定技能包归并方向）

**本书结构主干：概念型**

理由：全书二十四篇按"名→体→数→生→配→杂→德→合→扶抑→克→刑→害→冲破→配属→情性→人象"的**概念链**分章，既非按格局分章，也非按人生领域分章，更无月令×日干矩阵。

**但需加一层修正**：本书的概念全部落在 L1/L3（四柱载体、五行底层），**没有进入 L4-L8（技法/格局/用神/神煞/大运/断事）**。故归并方向不是"一个概念一个技能"地照搬二十四篇，而是把二十四篇归并成**五个底层零件组**，每组对应八字分析中的一个固定检查层：

| 零件组 | 对应八字分析中的哪一步 |
| --- | --- |
| 名义与体性 | 认星、认五行性质、判"失性"之象 |
| 数理与纳音 | 查生成数、太玄数、纳音、空亡孤虚 |
| 旺衰与生克 | 判旺相休囚死、判生克能否成立、判扶抑向背 |
| 刑冲合害德 | 判干支关系的性质与力度 |
| 取象 | 由五行干支落到性格、体质、病位、色声气味 |

> 这个判断将决定第 5 步的技能归并方向。

### 作者的断法风格

- **流派倾向**：象数派 / 五行理论派。不属于格局派、旺衰派、盲派中的任何一支——它比这些流派都早，是它们的共同上游。
- **推理路径偏好**：名 → 体性 → 数 → 气之流转（生死、休王）→ 干支关系（德合刑害冲）→ 配属取象。**从本体推象，不从盘推命**。
- **命例使用习惯**：完全不用命例；用经典互证（郑玄、服虔、京房、翼奉、许慎、《白虎通》、《春秋繁露》、《元命苞》）+ 设问自答（"问曰…答曰…"）来立论。
- **遇异说的处理**：不回避分歧，逐条列出两说再判优劣。如六气配五行，服虔与郑玄相反，萧吉判"服近之"；五常配五行，郑玄诗纬以土为智、毛公京房汉志以土为信，萧吉判"毛公及京房、汉史，皆以土为信，可谓其当"。

## 盲点与边界

### 时代与流派局限

1. **早于四柱**。萧吉卒于隋大业年间，李虚中三命术在唐中期才成型，徐子平更晚。本书根本没有"年月日时四柱"这个概念，也没有日主、十神。拿它断命，等于拿解剖学教材看病。
2. **服务对象是帝王政教**。辨体性、配五事、论治政三篇，落点全是"人君失威仪则木失其性""人君不明则火失其性"。它的吉凶观是**灾异谴告**，不是个人命运。把"木不曲直"直接读成"某人肝胆有病"，是跨了一层。
3. **材料来源是纬书与经注**。大量引《春秋元命苞》《诗纬推度灾》《孝经援神契》《礼斗威仪》这类谶纬，其中相当部分是汉代政治神学，不是术数实证。这部分只能当"古人怎么想"，不能当"这样断准"。

### 未被证明的假设

1. **"名以定体"**——认为给一个东西定了名，就抓住了它的体。这是全书的方法论前提，也是它最脆弱的一环：名是训诂，训诂是语源联想（木=触、水=准），从语源推物理性质，逻辑上不成立。
2. **"五行同时俱起，托义相生"**——五行并非真有先后相生，只是"托义"（借一个道理）说成相生。作者自己承认了这一点，却仍用相生推一切。承认了假设是假设，还照用。
3. **配属可无限外推**——五行能配五色、五音、五味、五藏、五常、五事、五谷、五菓、五菜、五畜、五方、五帝、五岳、二十八宿……配得越广，单条配属的信息量越低。八字的取象体系继承了这个毛病。

### 方法的失效场景

1. **任何需要"这个八字会怎样"的问题，本书都答不了**。无日主、无十神、无格局、无大运、无命例。婚姻、事业、财运、六亲、学业五个维度全空。
2. **本书的旺衰是"某行在某月的旺衰"，不是"日主在某盘的旺衰"**。前者是常量表，后者要考虑通根、透干、合化、沖克。直接用四时休王表给日主定强弱，会得出"春天生人一律身强"这种荒谬结论。
3. **本书的"扶抑"不是用神法的扶抑**。把它当"身弱喜扶、身强喜抑"用，是把母子的伦理比喻误读成力量的加减。
4. **纳音部分只讲"数怎么来"，不讲"纳音怎么断"**。要断纳音吉凶，本书帮不上。

### 最强的反驳

> 这套体系是"配出来的"，不是"验出来的"。它从训诂定名、从数定序、从类比定配属，全程没有一处用可重复的观察去检验。五行配五藏能自圆其说，配五音也能自圆其说，正因为什么都能配，所以什么都不构成预测。而八字要的是预测——给定四柱，输出一个可被证伪的结论。本书提供的是词汇表，不是预测模型。

### 与其他流派的冲突点

1. **与子平格局派**：本书无格局。格局派以月令取格为第一步，本书连"月令"都不作命理义使用（"月令"在本书指《礼记·月令》篇）。
2. **与旺衰派**：本书四时休王是常量表，旺衰派要算通根透干、得地得生得助。两者层级不同，混用会失真。
3. **与神煞派**：本书的德是气不是神，五合五离是日辰选择不是命局神煞。神煞派把支德直接当天德月德用，中间省掉了月气德刑这一层。
4. **与纳音派**：本书给出纳音数的算法（支属八卦、一言至九言），但明说"此并候病之法，非通常用"（游年条）。纳音派把它发展成独立断法，已超出本书范围。
5. **内部冲突**：五常配五行，郑玄诗纬"土智水信" vs 毛公京房汉志"土信水智"，萧吉判后者为当，但未给出决定性论证，只说"此理寘证狭，于义乖也"。此处属作者裁决，非定论。
