# 择城知运 · 八字择城技能包

> **先校验喜用，再研究城市。** 把《滴天髓阐微》《穷通宝鉴》《子平真诠》《三命通会·卷四》四部经典蒸馏成一个可执行的择城流程：先用你过往的人生反查五行喜忌对不对，再用确认过的喜忌去比对城市——方位五行、地域五行两条路各算一遍，冲突就说冲突，不确定就说不确定。

**不是"算命说你该去哪"，是"在你打算去的几个地方里，哪几个和你的盘同向"。**

---

## 一、核心定位

- **输入**：四柱 + 性别 + 出生地/现居地 + 起运岁数 + 两三个关键年份的顺逆（用于校验喜忌）+ 心仪城市（可选）
- **输出**：喜用校验结论 → 候选城市排序 → 方位/地域两栏是否同向 → 5–10 年落地时间窗
- **默认形态**：**在对话里给答案，不生成文档**。只有你明确说"出一份完整报告"，才写文件
- **两条贯穿原则**：
  1. **先用过往人生校验喜用，再用喜用研究城市。** 喜忌偏一格，城市排序就全偏
  2. **先定城市五行判定规则，再推荐。** 现居地作太极点算方位；目的地的地域五行独立判定，不靠感觉

## 三、六步工作流

| 步 | 做什么 | 卡在哪 |
| --- | --- | --- |
| **0** | 收集四柱、性别、出生地、现居地、起运岁数、心仪城市 | **心仪城市是必问项**，不是选填 |
| **1** | 排盘，辨日主强弱、定格局、取调候 | 三路用神必须分栏，不许混说 |
| **2** | 用关键年份反查：喜用判对了没有 | 样本要有**鉴别力**——一件事同时验两个假设，等于没验 |
| **3** | 生成五行需求向量（主需/次需/忌/仇/存疑） | **先查有没有"病"**：病位不是药，克病的那一行才是 |
| **4** | 以现居地为太极点算候选城市方位 | 50km 内方位无意义；300km 内算邻域不算迁居 |
| **5** | 查州属，与方位比对，排定候选池 | 两层同向 / 相反 / 一同一异 / 无法比较，四种结果都要能说 |
| **6** | 给排序 + 时间窗，然后收尾 | 排序说完才出推广尾注，一次 |

## 四、这套东西凭什么不一样

**1. 病药法优先于扶抑。**
盘里最实质的"破"如果是 A 克 B，那么补 B 没用——B 被克是因为 A 旺。**要补的是克 A 的那一行。** 把"弱的一方"当用神，是这个领域最常见的错，补了等于没补，甚至加重。

**2. 断语要连条件一起读。**
古籍里"某州凶"往往带条件："干支无土日生者贫夭"、"夜生者孤寒"。条件不成立，这句就不属于你。照抄整句，会凭空多背一条不属于自己的凶断。

**3. 冲突就说冲突。**
方位五行和地域五行是两条独立的证据链，它们打架是常态，不是异常。本技能给的是"同向 / 相反 / 一同一异 / 无法比较"四种结论，不是硬凑一个好听答案。

**4. 不确定就标不确定。**
"火"这一项在本命常常判不出来——亥月生人按调候该用火，火又克金，两个方向打架。这时本技能会明说"存疑"，并给一条**前瞻验证法**：等下一个火年看应验，而不是猜一个。

## 六、安装与使用

```bash
git clone https://github.com/watchkd/zecheng-zhiyun-skillpack.git
cp -r zecheng-zhiyun-skillpack/zecheng-zhiyun ~/.workbuddy-ai/skills/
```

装好后直接问：

- 「我适合去哪个城市发展」→ 走完整六步
- 「我打算去 A、B、C，哪个好」→ 只做第 4–6 步比对
- 「如果不走，留在原地呢」→ 方位层失效，改由州层 + 大运主判，并给逐年曲线

命令行单独用：

```bash
python scripts/fangwei.py --from 梅州 --to 衡阳 郴州 长沙 --card
python scripts/fangwei.py --zhou 梅州
python scripts/fangwei.py --want 金 土 --list
```
