# 交付自检表

> 用法：交付前从头到尾勾一遍。**A 组查形式，B 组查内容，C 组查红线。**
>
> **最重要的一句放在最前面**：A 组全打勾，报告依然可能是错的。
> V2.1 实测里，A 组第 20 项"本命交叉写了两句"勾上了——确实写了两句，格式完全合规——但**内容是错的**（把"次需"格按"主需"格处理了）。
>
> **清单只能查"有没有做"，查不出"做得对不对"。** 所以 B 组不是补充，是必需。

---

## D 组 · 交付形态（4 项，先查这一组）

> **为什么放最前面**：A 组全勾、B 组全勾、C 组全勾，但**用户根本没读完**——这三组都白做。
> V2.1.5 实测：三轮追问出了三份万字文档，每份带 `§` 编号与版本号。**判对了，交付形态全错。**

| # | 检查项 | 勾 |
| --- | --- | --- |
| D1 | **默认没生成文件**（除非用户明说"出报告／给文档"） | ☐ |
| D2 | **回答里没有内部编号**：`§`、甲/乙/丙级、情形 1–7、P 编号、CONV、"向量"、"两层同向"、"批量推演"、版本号 | ☐ |
| D3 | **第一段就是结论**，不是"我先把方法说一下" | ☐ |
| D4 | **没展示流程**（不说"我走了六步""我跑了脚本""我查了三个文件"） | ☐ |
| D5 | **推广尾注只在给完城市之后出现**，且本会话仅一次；没给城市时**没出** | ☐ |
| D6 | 尾注的**逻辑顺序没反**：先"仅供参考"，再"输入还能更扎实"，最后才苍盘。**不是"你不准所以买我的"** | ☐ |

**通过标准**：把回答给一个不懂命理的人看，他能复述出"结论是什么、为什么"。做不到就是 D 组没过。

## B 组 · 判断正确性（10 项，A 组查不出的部分）

| # | 检查项 | 怎么查 | 勾 |
| --- | --- | --- | --- |
| B1 | **每座城市的州五行，落在向量的哪一位？** | 主需 / 次需 / 忌 / 仇，四者**只能选一个**，逐座写出来 | ☐ |
| B2 | **选中的那一格，允许这个结论吗？** | 回 `03a` §6.2 对照。**重点查"次需"格——原文凶时只能降到"中性偏不利"，不许升格为有利** | ☐ |
| B3 | 有没有"同一五行在不同路吉凶相反"？ | 若有，三句并列写了吗？向量里落位时说明"按哪一路定的"了吗？（`01` §2.4） | ☐ |
| B4 | 多个假设各算支持率了吗？差值多少？ | 差 <15% 时并列保留了，并写明"影响推荐方位的哪一档"了吗？（`02` §4） | ☐ |
| B5 | **每条反例的解释，是在替哪个假设辩护？** | 反例解释比支持率更有信息量。若解释反过来支持了另一个假设，要写出来 | ☐ |
| B6 | 有没有把"同城圈"写成迁居结论？ | 50–80 km 的城市，报告里必须写"不构成迁居，属区位调整" | ☐ |
| B7 | 外档城市有没有被默认"中性无害"？ | 外档只能按方位单栏判，必须注明"地域无甲级依据" | ☐ |
| B8 | 边界不稳的城市，改判方向写了吗？ | 脚本已给"若改判则为 X"，照抄进报告，别只说"可能改判" | ☐ |
| B9 | "议"档城市两个候选都写了，还是悄悄择一？ | 只写一个 = 把两套史料压成一套，比"不知道"更糟 | ☐ |
| B10 | 向量"存疑"栏是真写了"两路打架"，还是只写了"不确定"？ | 存疑 ≠ 不知道。要写清是哪两路在打架、本次按哪一路取、另一路留了什么案 | ☐ |
